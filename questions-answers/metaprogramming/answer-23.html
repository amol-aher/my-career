Implement a Proxy / Delegator class in Ruby (without Forwardable)

We'll show a robust implementation that supports delegation, introspection (respond_to?), and optional explicit delegators defined at class-level.

Simple dynamic delegator using method_missing

class SimpleProxy
  def initialize(target)
    @target = target
  end

  def method_missing(name, *args, &blk)
    if @target.respond_to?(name)
      @target.public_send(name, *args, &blk)
    else
      super
    end
  end

  def respond_to_missing?(name, include_private = false)
    @target.respond_to?(name, include_private) || super
  end
end

# Usage
proxy = SimpleProxy.new([1,2,3])
proxy.push(4)       # delegated to Array#push
proxy.respond_to?(:push) # => true

Adding explicit delegator definitions (performance & discoverability)

class Delegator
  def self.delegate(*methods, to:)
    methods.each do |m|
      define_method(m) do |*args, &blk|
        __send__(to).public_send(m, *args, &blk)
      end
    end
  end

  def initialize(target) @target = target end
  private
  attr_reader :_target
end

class MyWrapper < Delegator
  delegate :push, :pop, to: :_target
end

This defines concrete methods and avoids method_missing overhead and improves IDE discoverability.

Per-instance delegators (define_singleton_method)

obj = Object.new
target = [1,2]
%w[push pop].each do |m|
  obj.define_singleton_method(m) { |*a, &b| target.public_send(m, *a, &b) }
end

Considerations

  • Performance: method_missing is flexible but slower than concrete methods. Use define-on-first-call to optimize repeated calls.
  • Visibility: Use public_send to avoid calling private methods on target.
  • Thread-safety: Defining methods at runtime requires synchronization in multi-threaded apps.
  • Introspection: Implement respond_to_missing? so callers and libraries see the delegated methods.

Advanced: define-on-first-call pattern

class FastProxy
  def initialize(target) @target = target end

  def method_missing(name, *args, &blk)
    if @target.respond_to?(name)
      # Define method on the proxy class for speed
      self.class.define_method(name) do |*a, &b|
        @target.public_send(name, *a, &b)
      end
      send(name, *args, &blk)
    else
      super
    end
  end

  def respond_to_missing?(name, include_private=false)
    @target.respond_to?(name, include_private) || super
  end
end

Summary

Forwarding can be implemented simply with method_missing and respond_to_missing?. For performance and clarity, prefer explicit delegate/define_method definitions or define-on-first-call strategies.
