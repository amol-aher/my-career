Examples of metaprogramming techniques across multiple languages

Below are short examples and explanations for how different languages provide metaprogramming: compile-time vs runtime approaches are both included.

Ruby (runtime metaprogramming)

class User
  [:name, :email].each do |attr|
    define_method(attr) { instance_variable_get("@#{attr}") }
    define_method("#{attr}=") { |v| instance_variable_set("@#{attr}", v) }
  end
end

Python (dynamic attributes, decorators, metaclasses)

# setattr/getattr and decorators
class Proxy:
    def __init__(self, target):
        self._target = target
    def __getattr__(self, name):
        return getattr(self._target, name)

# metaclass example (modify class at creation)
class AutoRepr(type):
    def __new__(cls, name, bases, attrs):
        if '__repr__' not in attrs:
            attrs['__repr__'] = lambda self: f"<{name} {self.__dict__}>"
        return super().__new__(cls, name, bases, attrs)

JavaScript (proxies, dynamic properties)

// Proxy example
const target = {a:1};
const p = new Proxy(target, {
  get(obj, prop) {
    if (!(prop in obj)) return `missing ${String(prop)}`;
    return obj[prop];
  }
});
p.b // "missing b"

Java (reflection & annotation processing)

// Reflection
Method m = obj.getClass().getMethod("doSomething");
m.invoke(obj);

// Compile-time code generation: Annotation processors create .java files at build time (e.g. Dagger, AutoValue)

C++ (templates & macros)

// Template metaprogramming (compile-time)
template<int N> struct Factorial { static const int value = N * Factorial<N-1>::value; };
template<> struct Factorial<0> { static const int value = 1; };

/* Factorial<5>::value is computed at compile time */

Rust (macros)

// Declarative macro
macro_rules! create_fn {
  ($name:ident) => {
    fn $name() { println!("Called {}", stringify!($name)); }
  };
}

create_fn!(hello);
hello();

Takeaway

Metaprogramming exists on a spectrum: some languages favor runtime manipulation (Ruby, Python, JS), others emphasize compile-time transformations (C++ templates, Rust macros, Java annotation processors). Choose the right tool based on performance, safety, and developer ergonomics.
