Generate Ruby classes with attributes and validations from a JSON Schema

This is a common metaprogramming task: convert a JSON schema into runtime Ruby classes with attribute readers/writers and validations.

High-level approach

  1. Parse the JSON schema.
  2. For each "object" definition, create a Class (or reuse existing) using Class.new and set a constant.
  3. Define attribute accessors (attr_accessor) or typed readers.
  4. Map schema validation keywords to ActiveModel validations (presence, format, length, numericality).
  5. Cache generated classes to avoid redefinitions.

Example implementation (minimal)

require 'json'
require 'active_model' # for validations

def generate_class_from_schema(name, schema)
  klass = Class.new do
    include ActiveModel::Validations
    attr_accessor(*schema.fetch('properties', {}).keys)

    # build validators
    schema.fetch('properties', {}).each do |attr, opts|
      if opts['minLength'] || opts['maxLength']
        validates_length_of = {}
        validates_length_of[:minimum] = opts['minLength'] if opts['minLength']
        validates_length_of[:maximum] = opts['maxLength'] if opts['maxLength']
        validates attr.to_sym, length: validates_length_of unless validates_length_of.empty?
      end

      if opts['pattern']
        validates attr.to_sym, format: { with: Regexp.new(opts['pattern']) }
      end

      if opts['type'] == 'integer' || opts['type'] == 'number'
        validates attr.to_sym, numericality: true
      end
    end

    define_method(:initialize) do |hash = {}|
      hash.each { |k,v| public_send("\#{k}=", v) if respond_to?("\#{k}=") }
    end
  end

  Object.const_set(name, klass) unless Object.const_defined?(name)
  klass
end

# Usage:
schema = {
  'type' => 'object',
  'properties' => {
    'name' => {'type' => 'string', 'minLength' => 2},
    'age' => {'type' => 'integer', 'minimum' => 0}
  }
}
User = generate_class_from_schema('User', schema)
u = User.new('name' => 'Ada', 'age' => 28)
u.valid? # => true

Considerations and extensions

  • Nested objects: Recursively generate nested classes and reference them in attribute types.
  • Arrays: Map items to element type validators.
  • Type coercion: Consider adding type casting (e.g., convert numeric strings to integers).
  • Schema refs ($ref): Resolve references and avoid duplicate class generation by caching.
  • Security: Never generate classes with names from untrusted input without sanitization.

Testing

Auto-generated classes must be covered by tests ensuring mapping correctness and that validations match schema constraints.

Summary

Converting JSON schema into runtime classes is straightforward with Class.new, attr_accessor, and ActiveModel::Validations. Handle nested schemas, caching, and security carefully.
