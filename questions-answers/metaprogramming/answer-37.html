Automatically log method calls without modifying each method

There are several approaches. The cleanest and least invasive is to use Module#prepend to add a wrapper module that instruments calls via super. Alternatives include method_added to wrap methods at definition time or TracePoint for global tracing.

1. Instrument class methods using prepend

module MethodLogger
  def self.prepended(base)
    base.instance_methods(false).each do |m|
      wrap_method(base, m)
    end
  end

  def self.wrap_method(base, m)
    base.class_eval do
      original = instance_method(m)
      define_method(m) do |*args, &blk|
        logger = defined?(Rails) ? Rails.logger : STDOUT
        logger.puts "CALL \#{self.class}##{m} args=\#{args.inspect}"
        result = original.bind(self).call(*args, &blk)
        logger.puts "RETURN \#{self.class}##{m} => \#{result.inspect}"
        result
      end
    end
  end
end

class Worker
  prepend MethodLogger
  def run(x); x * 2 end
end

# Usage
Worker.new.run(3) # logs call and return

2. Wrap methods as they are defined (method_added)

module AutoLog
  def method_added(name)
    return if @_logging || name.to_s.start_with?("_logged_")
    @_logging = true
    original = instance_method(name)
    define_method(name) do |*a, &b|
      puts "CALL #{name} \#{a.inspect}"
      original.bind(self).call(*a, &b)
    end
    @_logging = false
  end
end

class Foo
  extend AutoLog
  def bar(x); x+1 end
end

Foo.new.bar(2) # logs

3. Global tracing with TracePoint (non-invasive)

TracePoint.trace(:call) do |tp|
  puts "CALL #{tp.defined_class}##{tp.method_id}"
end

TracePoint is powerful but heavy; prefer for debugging or sampled tracing.

Choosing an approach

  • Prepend is clean and efficient for a known set of classes.
  • method_added works when you control class definitions and want automatic wrapping at definition time.
  • TracePoint is best for short-lived diagnostics or central APM collectors.

Production considerations

  • Make logging levels configurable and avoid verbose logging in hot paths.
  • Consider structured logging (JSON) for easier aggregation.
  • Monitor overhead — use sampling or async logging if necessary.

Summary

Use prepend for predictable instrumentation, method_added for automatic wrapping, and TracePoint when you need broader tracing. Always profile and tune logging in production.
