How to Connect GitHub / GitLab / Bitbucket to AWS CodePipeline

Recommended: Use CodeStar Connections (for GitHub / Bitbucket)

CodeStar Connections provides a secure, managed connection between CodePipeline and third-party Git providers (GitHub, GitHub Enterprise, Bitbucket). It avoids storing personal access tokens and uses OAuth under the hood.

Steps for GitHub (CodeStar Connections)

  1. In the AWS Console, go to CodeStar Connections and create a new connection.
  2. Choose GitHub (or GitHub Enterprise) and follow the OAuth flow to authorize the connection.
  3. In CodePipeline, create a Source action and select the CodeStar Connection you created; choose repository and branch.
  4. When commits are pushed, CodePipeline is triggered automatically via the connection/webhook.

GitLab integration options

GitLab is not directly supported by CodeStar Connections. Options:

  • Use GitLab CI to push artifacts to S3/ECR and trigger CodePipeline from an S3 source or by calling StartPipelineExecution via the AWS SDK/webhook.
  • Use a webhook: Configure GitLab to call an API Gateway endpoint that triggers a Lambda which starts the pipeline.
  • Self-hosted integration: Use a small bridge service or Jenkins to act as the source trigger for CodePipeline.

Security & best practices

  • Prefer CodeStar Connections or OIDC for secure, short-lived credentials.
  • Limit repository access, and create separate connections per organization/project if necessary.
  • Use branch filters to avoid triggering pipelines for irrelevant branches.

Example: Triggering CodePipeline from GitLab via Lambda

1. Create API Gateway endpoint (POST) that invokes a Lambda.
2. Configure GitLab webhook to POST commit events to the endpoint.
3. Lambda validates the payload and calls StartPipelineExecution for the target pipeline via the AWS SDK.

Subquestions & answers

Q: Can I use OIDC with GitHub Actions to avoid tokens?

A: Yes — use GitHub Actions OIDC to obtain temporary AWS credentials and call CodePipeline/StartExecution or push artifacts to S3/ECR securely without long-lived secrets.

Q: How do I handle monorepos?

A: Use path filters in the source action or inspect commits in a webhook to decide which pipeline(s) should run. Alternatively, split into smaller repositories if feasible.

Conclusion

Use CodeStar Connections for the simplest, secure integration with GitHub/Bitbucket. For GitLab, use webhooks or leverage GitLab CI to push artifacts and trigger pipelines. Always prefer short-lived credentials and least-privilege access.
