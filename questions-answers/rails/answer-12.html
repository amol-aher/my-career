Caching Mechanisms in Ruby on Rails

Layered Caching Strategy

1. Fragment Caching

Cache partial page segments:

# app/views/products/show.html.erb <% cache product do %> <%= render product %> <% end %>

2. Russian Doll Caching

Nested fragment caching:

# app/views/orders/_line_item.html.erb <% cache line_item.product do %> <%= render line_item %> <% end %>

3. Low-Level Caching

Direct Redis/Memcached usage:

# app/services/product_service.rb def expensive_calculation Rails.cache.fetch("product_#{id}", expires_in: 1.hour) do # Complex calculation... end end

4. Cache Digests

Automatic invalidation when dependencies change:

# app/views/products/index.html.erb <% cache products, skip_digest: true do %> <% products.each do |product| %> <%= render product %> <% end %> <% end %>

Memcached Data Store Configuration

Typical memcached setup in Rails:

# config/caches.yml memcached: servers: - localhost:11211 namespace: my_app_production expires_in: 1.day

Best Practices

  • Use cache digests for automatic invalidation
  • Set appropriate expiration times
  • Handle cache misses gracefully
  • Monitor cache hit rates
