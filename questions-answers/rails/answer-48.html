Rails Engines: Architecture and Usage

Rails engines are mini-applications that can be mounted within a main application. They encapsulate related functionality, allowing for better organization and reusability of code.

Core Characteristics:

  1. Isolation: Engines have their own routes, controllers, models, and views
  2. Mountable: Can be mounted at specific paths in the parent application
  3. Reusable Components: Ideal for shared functionality across projects
  4. Autoloading: Follow Rails autoloading conventions

When to Use Engines Instead of Gems:

Sub-question: What are the advantages of engines?

  • Code Organization: Group related functionality together
  • Shared Functionality: Easily share complex features across multiple apps
  • Customization: Override engine components while keeping core functionality
  • Namespacing: Prevent naming conflicts between applications
  • Testing: Test engines independently from the main application

Sub-question: When would you prefer gems?

  • Simple Utilities: Small, focused pieces of functionality
  • Low Coupling: When minimal dependencies are preferred
  • Performance: Gems typically have less overhead than engines
  • Simplicity: For straightforward additions without complex routing

Sub-question: How to create a Rails engine?

Create a new engine using the Rails generator:

$ rails plugin new my_engine --mountable

This generates a basic engine structure with:

  • Separate routes file
  • Controllers, models, and views directories
  • Engine class definition
  • Test directory

To mount the engine in your main application:

# config/routes.rb
mount MyEngine::Engine => "/my_engine"

Sub-question: How to override engine views and controllers?

You can customize engine components in the main application:

Overriding Views:

Create view templates in the same path as the engine but under `app/views`:

# Main App Structure:
app/
└── views/
    └── my_engine/
        └── users/
            └── index.html.erb

Overriding Controllers:

Inherit from the engine controller and redefine actions:

# app/controllers/my_engine/users_controller.rb
class MyEngine::UsersController < MyEngine::ApplicationController
  def index
    # Custom logic here
  end
end
