Polymorphic Associations in Rails

Concept and Implementation

What are Polymorphic Associations?

A way to associate a single model with multiple other models using a single foreign key field.

When to Use Them

  • Comments on posts, photos, and videos
  • Attachments to different resource types
  • Tags across various models

Database Schema

# Migration example create_table :comments do |t| t.text :content t.references :commentable, polymorphic: true end

Model Definitions

# Post model class Post < ApplicationRecord has_many :comments, as: :commentable, dependent: :destroy end # Photo model class Photo < ApplicationRecord has_many :comments, as: :commentable, dependent: :destroy end # Comment model class Comment < ApplicationRecord belongs_to :commentable, polymorphic: true end

Querying Polymorphic Data

# Finding comments on any commentable Comment.where(commentable_type: 'Post') # Eager loading Comment.includes(:commentable) # Creating new comments comment = Comment.new(content: "Great post!") comment.commentable = post # or photo, etc. comment.save

Advantages Over STI (Single Table Inheritance)

Feature Polymorphic Associations STI
Schema Complexity Simple (single table) Complex (multiple tables)
Query Flexibility More flexible querying Stricter type-based queries
Storage Efficiency Better for sparse attributes Better for dense attribute sets

Potential Challenges

  • Complex querying with conditions on both sides
  • Indexing considerations for polymorphic type column
  • Serialization/deserialization complexities
