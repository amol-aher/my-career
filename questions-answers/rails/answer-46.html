ActiveModel vs ActiveRecord in Rails

Understanding the distinction between ActiveModel and ActiveRecord is crucial for effective Rails development. While both facilitate object-relational mapping, they serve different purposes.

ActiveRecord Overview

ActiveRecord is the ORM layer in Rails that provides database interaction capabilities:

  • Database Integration: Maps Ruby classes to database tables
  • CRUD Operations: Provides methods for creating, reading, updating, and deleting records
  • Associations: Manages relationships between models (has_many, belongs_to, etc.)
  • Validations: Enforces business rules at the model level
  • Migrations: Manages database schema evolution

ActiveModel Overview

ActiveModel provides a subset of ActiveRecord functionality for non-database models:

  • Model Abstraction: Allows plain Ruby objects to interact with Rails features
  • Validation Framework: Reuses ActiveRecord's validation system
  • Callbacks: Supports lifecycle callbacks similar to ActiveRecord
  • Serialization: Provides methods for converting objects to/from formats like JSON
  • Internationalization: Integrates with Rails I18n system

Sub-question: When to use each?

Scenario Recommendation Reason
Database-backed models ActiveRecord Provides full ORM functionality
Form objects ActiveModel Encapsulates complex form logic
API resources ActiveModel::Serializers Standardized JSON output
Service objects ActiveModel Reuses validation and callback infrastructure
Background jobs ActiveModel Consistent interface with other models

Sub-question: How to implement ActiveModel in a plain Ruby class?

# app/models/contact_form.rb
class ContactForm
  include ActiveModel::Model
  
  attr_accessor :name, :email, :message
  
  validates :name, presence: true
  validates :email, presence: true, format: { with: URI::MailTo::EMAIL_REGEXP }
  validates :message, length: { minimum: 10 }
  
  def submit
    # Business logic for form submission
  end
end

This class can now be used in controllers similarly to ActiveRecord models:

# app/controllers/contacts_controller.rb
def create
  @contact_form = ContactForm.new(contact_params)
  
  if @contact_form.valid?
    @contact_form.submit
    redirect_to thank_you_path, notice: 'Message sent successfully!'
  else
    render :new
  end
end

Sub-question: What are the key differences?

Feature ActiveRecord ActiveModel
Database Interaction Yes (full ORM) No
