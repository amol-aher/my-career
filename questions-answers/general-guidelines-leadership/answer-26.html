Tools, Websites, and Books I Use to Learn

Websites

  • Official documentation for languages/frameworks (Ruby docs, Rails guides, Vue docs).
  • StackOverflow, GitHub issues, and Discussions.
  • Dev.to, Medium engineering blogs, company tech blogs (Shopify, GitHub, Netflix).

Tools

  • Interactive REPLs (irb, pry, ipython, node REPLs).
  • Playgrounds like JSFiddle, CodePen, or local Docker setups.
  • Testing sandboxes in AWS or Heroku.

Books

  • Design Patterns: Elements of Reusable Object-Oriented Software (GoF)
  • Refactoring by Martin Fowler
  • Clean Code by Robert C. Martin
  • Release It! by Michael Nygard
  • The Pragmatic Programmer
