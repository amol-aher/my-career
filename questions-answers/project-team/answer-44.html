Deciding what to delegate vs handle myself

System architect · Technical lead · Senior software engineer (Ruby on Rails, AWS, SQL, Vue.js)

Summary: I delegate tasks based on risk, visibility, and development opportunity. I handle high-risk architecture, cross-team decisions, and sensitive stakeholder communications myself, while delegating implementation tasks to empower team members.

Delegation framework
  • Delegate: routine coding tasks, bug fixes, feature subtasks, and monitoring improvements.
  • Retain: architecture decisions, incident coordination, high-visibility demos, and sensitive stakeholder discussions.
  • Stretch assignments: delegate challenging but safe tasks to grow senior engineers.
Example

In a payments project, I delegated API implementation to a mid-level dev, while I handled the schema migration strategy and client compliance calls.
