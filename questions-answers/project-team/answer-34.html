Project management tools & methodologies used

System architect · Technical lead · Senior software engineer (Ruby on Rails, AWS, SQL, Vue.js)

Summary: I have used Agile, Scrum, Kanban, Waterfall (for select contracts), and hybrid models. Tools: Jira, Confluence, GitHub/GitLab, Clubhouse (Shortcut), Trello, and CI/CD tools (GitHub Actions, CircleCI), Slack for ops/alerts, and AWS tooling for infra management.

How I choose methodology
  • Scrum for predictable feature delivery and demos.
  • Kanban for ops-heavy teams or support flows.
  • Waterfall for fixed-scope vendor contracts with long procurement cycles.
Tooling & integrations
  • Jira for backlog and sprints, Confluence for docs.
  • GitHub PR templates and protected branches for quality gates.
  • CI/CD integrated to Jira for status updates and deployment tracking.
  • Monitoring: Datadog, CloudWatch, Sentry for errors.
