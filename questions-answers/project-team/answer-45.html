Managing a low-performing team member

System architect · Technical lead · Senior software engineer (Ruby on Rails, AWS, SQL, Vue.js)

Summary: Approach performance issues with empathy, structured feedback, and a measurable improvement plan. Escalate to formal HR processes only if needed.

Process I follow
  1. Private 1:1 conversation: clarify expectations, listen for context.
  2. Set measurable goals: SMART (Specific, Measurable, Achievable, Relevant, Time-bound).
  3. Provide support: mentoring, pairing, training resources.
  4. Regular check-ins: weekly progress reviews.
  5. Escalate: if no improvement, initiate PIP with HR.
Example improvement plan
Goal: Reduce PR rework from 60% to <20% in 60 days
Actions:
- Pair programming 2x/week with senior
- Training on Rails patterns
- Weekly code review checklist
Check-ins: bi-weekly with manager
