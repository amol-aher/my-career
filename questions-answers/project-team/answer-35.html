Breaking down a large project into manageable tasks

System architect · Technical lead · Senior software engineer (Ruby on Rails, AWS, SQL, Vue.js)

Summary: Start with outcomes, create epics, slice into vertical user-value stories, then into implementation tasks with clear acceptance criteria and estimates.

Step-by-step
  1. Define success: what does 'done' look like?
  2. Create epics: group functionality by theme or milestone.
  3. Vertical slicing: split epics into stories that deliver end-to-end value.
  4. Sub-tasks: implement UI, API, DB, infra, tests, and docs for each story.
  5. Spike when unknown: time-box research to reduce uncertainty before sizing.
Example slice
Epic: Multi-address shipping
Stories:
- User can add an address (API + UI + tests)
- User can list and select address at checkout
- Admin can bulk import addresses
Each story: split into backend, frontend, tests, infra config
