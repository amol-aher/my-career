Implementing Decorator / Presenter in a Rails app

Purpose: Separate presentation logic from domain models. Presenters/Decorators format data for views (dates, currency, composed fields) and can wrap models to provide view-specific helpers.

Option 1 — Use Draper gem (common, feature-rich)

# Gemfile
# gem 'draper'

class ProductDecorator < Draper::Decorator
  delegate_all

  def display_price
    h.number_to_currency(object.price_cents / 100.0)
  end

  def title_with_brand
    "#{object.brand.name} — #{object.title}"
  end
end

# controller
def show
  @product = Product.find(params[:id]).decorate
end

# view
= @product.display_price

Option 2 — SimpleDelegator-based presenter (no gem)

class ProductPresenter < SimpleDelegator
  include ActionView::Helpers::NumberHelper

  def initialize(product)
    super(product)
  end

  def display_price
    number_to_currency(__getobj__.price_cents / 100.0)
  end
end

# usage
@presenter = ProductPresenter.new(Product.find(...))

Where to use presenters

  • Complex formatting used only by views
  • Composed values joining multiple models for display
  • Localizing strings or presentation rules without polluting models

Best practices

  • Keep presenters small and focused on presentation concerns.
  • Don't place business logic in presenters; they should read model state, not change it.
  • Favor decorators for view-specific helpers and service objects for domain logic.

Interview tip
