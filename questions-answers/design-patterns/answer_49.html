Rails' delegate method and the Delegation pattern

The Delegation pattern forwards method calls to another object. Rails provides delegate (and Forwardable) to define forwarding methods succinctly, reducing boilerplate and clarifying intent.

Example

class Order < ApplicationRecord
  belongs_to :user
  delegate :email, :name, to: :user, prefix: true, allow_nil: true
end

# usage
order.user_email # forwards to order.user.email

Options

  • prefix: true avoids name collisions by adding user_ prefix.
  • allow_nil: true prevents nil errors by returning nil if the target is nil.

When to use delegation

  • Keep model interfaces small and surface only needed methods.
  • Avoid exposing entire associated objects to callers when only a few attributes are needed.

Interview tip

Explain how delegation improved clarity in a codebase by avoiding deep chaining (e.g., order.user.profile.avatar_url) and where you preferred presenters over delegation for view-specific formatting.
