Observer pattern — explanation and Ruby example

Intent: define a one-to-many dependency so when one object changes state, all its dependents are notified automatically. Useful for event subscriptions, decoupling producers and consumers.

Simple example — a PriceTracker and multiple observers

module Observable
  def observers
    @observers ||= []
  end

  def add_observer(o)
    observers << o
  end

  def notify(event, payload = {})
    observers.each { |o| o.update(event, payload) }
  end
end

class PriceTracker
  include Observable

  def initialize(product)
    @product = product
  end

  def price_changed(new_price)
    # business logic
    notify(:price_changed, product: @product, price: new_price)
  end
end

class EmailNotifier
  def update(event, payload)
    return unless event == :price_changed
    puts "Email: price of #{payload[:product]} changed to #{payload[:price]}"
  end
end

class Analytics
  def update(event, payload)
    puts "Analytics: got #{event} for #{payload[:product]}"
  end
end

# usage
tracker = PriceTracker.new('widget')
tracker.add_observer(EmailNotifier.new)
tracker.add_observer(Analytics.new)
tracker.price_changed(19.99)

Ruby stdlib & alternatives

Ruby historically included an Observable module in the standard library, but it’s minimal. In Rails, ActiveSupport::Notifications is a powerful pub/sub facility for instrumenting events and decoupling listeners.

When to use

  • UI update propagation (MVC)
  • Cross-cutting event reactions (logging, metrics, notifications)
  • Decoupling components in plugin systems

Trade-offs

  • Observers add indirection — harder to trace control flow.
  • Order of notifications may matter; design contract for observers carefully.
  • Ensure performance — synchronous observers can slow the producer; consider async delivery via background jobs or message queues.

Interview tips

Show the simple module-based example and also mention Rails’ ActiveSupport::Notifications.instrument and using message buses (Kafka) for scaling observers across services.
