What experience do you have with Vue.js? How would you structure a Vue app?

Summary:
I have extensive experience building Vue apps (Vue 2 and Vue 3), using Options API and Composition API, migrating apps to Vue 3, implementing SSR with Nuxt, and building component libraries and design systems. I prefer component-driven design, strong typing with TypeScript, Pinia for state, and clear separation between presentation and business logic.

How I structure a Vue app (detailed):
1. Project scaffold: Vite (fast dev server, HMR) + TypeScript + ESLint + Prettier + Vitest + Cypress.
2. Directory layout (typical):
- src/
- assets/ (images, fonts)
- components/ (reusable UI components, atoms/molecules)
- composables/ (reusable hooks using Composition API)
- views/ (route-level components)
- pages/ (Nuxt convention)
- router/ (Vue Router setup)
- store/ (Pinia stores organized by domain)
- services/ (API clients, auth, utils)
- plugins/ (global plugins and third-party integration)
- types/ (shared TypeScript types)
- App.vue, main.ts
3. State management:
- Use Pinia for Vue 3 (modular stores per domain). Keep stores focused with explicit actions and getters.
- Prefer server-state libraries (Vue Query / TanStack Query) for caching API responses and handling background refreshes.
4. Component patterns:
- Small, testable components with clearly defined props and events.
- Use slots for flexible composition; expose events instead of mutating parents.
- Keep presentation vs container separation; containers fetch data and pass to presentational components.
5. Styling:
- Scoped CSS in SFCs or CSS Modules; use Tailwind if project favors utility-first.
- Centralize design tokens (colors/spacing) and support theming.
6. Testing & CI:
- Unit tests for components, integration tests for stores/services, E2E for critical flows, and visual regression tests for UI consistency.
7. Performance & UX:
- Lazy-load route components, code-splitting, image optimization, prefetching important resources, and SSR for SEO-critical pages.
8. Observability & monitoring:
- Integrate Sentry for errors, record user-impacting metrics, and instrument performance metrics (LCP, FID/INP).

Interviewer follow-ups:
- Q: How do you share code between Vue components and plain JS modules?
A: Create composables for logic reuse, extract utilities into `services` or shared npm packages if multiple apps need them.
- Q: How do you migrate a Vue 2 app to Vue 3?
A: Audit third-party deps for Vue 3 compatibility, migrate incrementally using compatibility build, update to Composition API patterns where beneficial, and run comprehensive tests.
