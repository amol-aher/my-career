Explain in detail flex in CSS?

Summary:
Flexbox is a CSS layout model designed for one-dimensional layouts (either row OR column). It simplifies distribution of space, alignment, and order of items inside a container. It's excellent for building responsive toolbars, navs, and component layouts.

Deep dive — key properties:
- Container: `display: flex` or `inline-flex`.
- Main axis vs cross axis: defined by `flex-direction` (row, row-reverse, column, column-reverse).
- Wrapping: `flex-wrap` allows items to wrap onto multiple lines.
- Justify & align: `justify-content` aligns along main axis; `align-items` aligns along cross axis; `align-self` overrides per-item.
- Flex sizing: `flex` shorthand (`flex-grow flex-shrink flex-basis`) controls how items grow/shrink relative to each other.

Common layout patterns:
- Centering: `display:flex; align-items:center; justify-content:center;` centers child both ways.
- Flexible sidebar: `container { display:flex; } main { flex: 1; } aside { width: 300px; }`
- Footer stick-to-bottom using column flex and `min-height:100vh`.

Examples:
```css
.container { display:flex; gap: 16px; align-items:center; justify-content:space-between; }
.item { flex: 1 1 200px; } /* grow, shrink, basis */
```

When to use Grid vs Flexbox:
- Flexbox: one-dimensional layouts and component-level alignment.
- CSS Grid: two-dimensional layouts (rows + columns) such as full page layouts or complex grids.
They are complementary and often used together.

Interviewer follow-ups:
- Q: What is the default `flex` value?
A: `0 1 auto` (no grow, can shrink, base size auto).
- Q: How to prevent flex items from shrinking?
A: Use `flex: 0 0 auto` or set `min-width`/`min-height` to enforce size.
