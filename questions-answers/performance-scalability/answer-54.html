Distributed Tracing (Jaeger, OpenTelemetry, AWS X-Ray)

What tracing provides

  • End-to-end request flows across services
  • Per-span timings (DB, external calls)
  • Error propagation and root-cause identification

How it helps debugging

  • Pinpoint which service or external call causes p99 latency
  • Visualize dependency graphs and hotspots
  • Correlate traces with logs and metrics

Implementation notes

  • Use OpenTelemetry SDKs to instrument HTTP clients, frameworks, DB drivers
  • Propagate trace context headers (W3C Trace Context)
  • Sample intelligently (tail-based sampling for p99)
