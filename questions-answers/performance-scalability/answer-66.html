How CloudFront Improves Global Performance

Key benefits

  • Edge caching: Cache static and dynamic content at edge locations close to users, reducing latency.
  • TLS termination & HTTP/2: Faster TLS handshakes and multiplexed requests.
  • Origin shield: Reduces load on origin by adding another caching layer.
  • Compression & optimized delivery: Brotli/Gzip and support for range requests.
  • Security integration: WAF integration, Shield and geo-restriction.
  • Lambda@Edge / CloudFront Functions: Run lightweight code at edge for personalization, A/B testing, auth.

Typical setup

Origin: S3 + ALB (API)
CloudFront distribution -> caches assets, forwards API requests to ALB with caching disabled or short TTLs.
Use signed URLs/CloudFront Functions to implement auth at edge.

Practical advice

  • Set proper Cache-Control and ETag headers on origin.
  • Use versioned asset filenames for easy invalidation.
  • Enable compression at origin or CloudFront for faster transfer.
  • Leverage Lambda@Edge for edge-based header rewrites or authorization checks.
