Optimizing ActiveRecord Queries for Large Datasets

Large datasets require careful query patterns to avoid memory blowups and long-running queries. Here are strategies and code examples.

1. Use pagination and batching

# ActiveRecord find_each batches by primary key (default batch_size 1000)
User.find_each(batch_size: 1000) do |u|
  process(u)
end

2. Select only required columns

Product.select(:id, :price).where(active: true).find_each do |p|
  # only id and price loaded
end

3. Use pluck for scalar results

emails = User.where(active: true).pluck(:email)

4. Indexes and EXPLAIN

Always validate queries with EXPLAIN and add appropriate indexes (including covering indexes).

5. Bulk operations

# activerecord-import or insert_all for bulk upserts
Model.insert_all(rows)

6. Use database-side filtering & aggregation

Shift aggregation to SQL where possible instead of loading rows into Ruby.

counts = Order.group(:status).count

7. When to use read replicas or OLAP stores

Move analytical heavy queries to read replicas or warehouses to avoid impacting transactional DB.
