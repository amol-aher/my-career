ALB, NLB, CLB — Differences & Recommendation for Microservices

CLB (Classic Load Balancer)

Legacy; supports basic Layer 4/7 features; use only for legacy apps.

ALB (Application Load Balancer)

  • Layer 7 (HTTP/HTTPS). Supports host/path-based routing, WebSocket, HTTP/2, stickiness via application cookies.
  • Good for microservices where routing and host-based rules are needed.

NLB (Network Load Balancer)

  • Layer 4. Extremely low latency, static IPs, TLS passthrough, handles millions of connections.
  • Use when you need extreme performance or static IPs.

Recommendation

For HTTP microservices, use ALB for its routing features. Use NLB for TCP-level performance or when you require static IP addresses. CLB is deprecated.
