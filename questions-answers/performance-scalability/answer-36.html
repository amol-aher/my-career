Pagination, Rate Limiting, and Throttling in Rails APIs

These patterns protect your service from overload and make APIs predictable for clients. Below are best practices and code examples.

Pagination strategies

  • Offset-based: Simple, page & per_page (kaminari, will_paginate). Not ideal for deep paging in large datasets.
  • Cursor-based: Use encoded cursors (id + sort field) for reliable, stable pagination for real-time data.
  • Keyset pagination: SQL where clauses (e.g., WHERE id < last_id ORDER BY id DESC LIMIT 25).

Cursor example

def index
  limit = (params[:limit] || 25).to_i
  if params[:cursor]
    last_id = Base64.decode64(params[:cursor]).to_i
    items = Item.where("id < ?", last_id).order(id: :desc).limit(limit)
  else
    items = Item.order(id: :desc).limit(limit)
  end
  next_cursor = items.any? ? Base64.encode64(items.last.id.to_s) : nil
  render json: { items: items, next_cursor: next_cursor }
end

Rate limiting & throttling

Use Rack::Attack with Redis as a backing store for counters and limits.

# Gemfile
gem 'rack-attack'

# config/initializers/rack_attack.rb
class Rack::Attack
  Rack::Attack.cache.store = ActiveSupport::Cache::RedisCacheStore.new(url: ENV['REDIS_URL'])

  # throttle by IP: 100 requests per minute
  throttle('req/ip', limit: 100, period: 1.minute) do |req|
    req.ip
  end

  # blocklist abusive IP
  blocklist('block bad UA') do |req|
    req.user_agent =~ /BadBot/
  end
end

Throttling patterns

  • Throttling by IP or API token.
  • Graceful responses: return 429 Too Many Requests and Retry-After header.
  • Exempt trusted clients (with keys) or allow higher quotas for paid tiers.

Monitoring & UX

Expose rate-limit headers (X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset) so clients can adapt. Monitor throttled requests and adjust thresholds.

Summary

Use cursor/keyset pagination for performance, Rack::Attack for rate-limiting, and design throttling rules to protect critical resources. Provide informative headers and 429 responses so clients handle limits gracefully.
