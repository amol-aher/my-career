Vertical vs Horizontal Scaling on AWS

Vertical scaling

Increase instance size (CPU, RAM) — quick but limited and often more expensive per performance unit. RDS instance resizing is a common vertical operation.

Horizontal scaling

Add more instances behind load balancers (EC2 ASG, ECS tasks, EKS pods, Lambda concurrency). Preferred for web tiers and most stateless services.

AWS specifics

  • RDS favors read replica (horizontal) for read scaling; vertical resizing for single-node performance.
  • Aurora scales storage automatically and supports read replicas for horizontal scaling.

Recommendation

Prefer horizontal scaling for elasticity and resilience; use vertical scaling for temporary relief or specialized needs.
