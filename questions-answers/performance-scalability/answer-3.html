Code-Level Performance Improvements

Beyond database and infra changes, code-level interventions often yield low-effort, high-impact gains.

1. Algorithmic Optimization

Replace O(n^2) loops with O(n log n) or O(n) algorithms; avoid repeated computations, memoize results where appropriate.

2. Reducing Allocations and GC Pressure

In Ruby, avoid creating unnecessary objects in hot paths — reuse strings, use symbols for static keys, use Enumerator and streaming to process large datasets.

3. Avoiding N+1

# Bad
orders.each do |o|
  puts o.user.name
end

# Good
orders.includes(:user).each do |o|
  puts o.user.name
end

4. Use Background Jobs

Shift synchronous work to async workers and return quickly to the caller. Ensure idempotency and retries with exponential backoff.

5. Efficient Serialization

When returning JSON, avoid serializing entire AR objects. Select fields and use fast serializers (Oj, fast_jsonapi).

6. Example: Batch Processing and Bulk Upsert

# Using activerecord-import
items = []
rows.each do |r|
  items << Item.new(r)
end
Item.import(items, on_duplicate_key_update: {conflict_target: [:external_id], columns: [:status, :updated_at]})

7. Circuit Breakers and Throttling

Protect critical resources with circuit breakers (e.g., GitHub's resilience4j or custom) and employ token-bucket throttling to smooth bursts.

8. Benchmarking Locally

Use benchmark-ips, ruby-prof, and memory_profiler to measure improvements and regressions.
