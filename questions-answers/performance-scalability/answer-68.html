CloudWatch Metrics, Logs, and Alarms — Differences

Metrics

Time-series numeric data points (CPUUtilization, RequestCount). Useful for dashboards and SLOs. Metrics have retention and resolution (1-minute, 1-second with higher granularity).

Logs

Unstructured or structured events (application logs, Lambda logs). Store in Log Groups and query with CloudWatch Logs Insights for ad-hoc analysis.

Alarms

Alarms monitor metrics and fire when thresholds are crossed. Alarms can trigger SNS notifications, auto-scaling, or automated actions.

Integration

  • Use Metric Filters to create metrics from logs (e.g., error count).
  • Use Logs Insights to debug and correlate traces.
  • Create dashboards that mix metrics and log-derived metrics for richer context.
