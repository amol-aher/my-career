Detecting & Mitigating DDoS Attacks with AWS Shield and WAF

Layered defences

  • Edge protection: Route traffic through CloudFront (or Global Accelerator) so attacks hit edge locations instead of origin.
  • AWS Shield: Standard is automatic for CloudFront/ALB; Shield Advanced provides DDoS cost protection, more telemetry and mitigation.
  • AWS WAF: Block/filter requests with rate-based rules, IP sets, geo-blocking, and managed rule groups.
  • Firewall Manager: Manage WAF rules centrally across accounts.

Detection

  • Monitor CloudFront/ALB request metrics and sudden spikes in request count, 4xx/5xx, and network-level metrics.
  • Use Shield Advanced alerts and AWS GuardDuty for suspicious activity.

Mitigation playbook

  1. Enable WAF rules to block obvious bad traffic (bots, bad UA, known bad IPs).
  2. Apply rate limiting rules (e.g., per-IP limit).
  3. Enable CAPTCHA/challenges for suspicious endpoints.
  4. Engage AWS Shield Advanced for large attacks and use their DRT in extreme cases.
  5. Scale edge caches and increase origin capacity if possible. Use origin failover and minimization of expensive dynamic work.
