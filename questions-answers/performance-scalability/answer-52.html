Implementing Retries and Exponential Backoff

Key ideas

  • Exponential backoff: wait times grow exponentially: base * 2^attempts.
  • Jitter: add randomness to avoid thundering herd (full jitter recommended).
  • Max retries and circuit breakers: combine with circuit breakers to stop wasting resources.

Example Ruby implementation

def with_retry(max_attempts: 5, base_sleep: 0.5)
  attempts = 0
  begin
    attempts += 1
    yield
  rescue TransientError => e
    raise if attempts >= max_attempts
    sleep_time = base_sleep * (2 ** (attempts - 1))
    sleep_time = sleep_time * rand # full jitter
    sleep(sleep_time)
    retry
  end
end
