Multi-AZ vs Multi-Region Deployments

Multi-AZ (Availability Zones)

Provides high availability within a single AWS region. Services replicate synchronously or semi-synchronously across AZs (RDS Multi-AZ, ElastiCache Multi-AZ). Failover is typically automatic and fast (seconds to minutes).

Multi-Region

Deploys across geographic regions (e.g., us-east-1 and eu-west-1). Protects against region-wide outages and reduces latency for global users. Involves async replication and manual/automated failover, higher RPO/RTO concerns and complexity.

When to use

  • Use Multi-AZ by default for HA inside region.
  • Add Multi-Region if you require regional isolation, compliance, or improved global latency and can bear the complexity.
