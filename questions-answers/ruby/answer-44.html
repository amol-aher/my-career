Question 44: Given a nested hash, can you flatten it so that nested keys are joined with a dot? Can you write pseudocode or actual code?

Concept

Flattening a nested hash involves walking the hash recursively and building new keys by joining parent keys with a separator (dot). Handle arrays, non-hash values, and collisions carefully.

Optimal answer (concise)

Recursively traverse the hash and accumulate key path segments, emitting key-value pairs where values are not hashes. Use a stack/recursion and join keys with '.' (or chosen separator).

Code (actual)

def flatten_hash(h, prefix = nil, sep = '.')
  result = {}
  h.each do |k, v|
    key = prefix ? "\#{prefix}#{sep}\#{k}" : k.to_s
    if v.is_a?(Hash)
      result.merge!(flatten_hash(v, key, sep))
    else
      result[key] = v
    end
  end
  result
end

nested = {a: {b: {c: 1}}, x: 2}
flatten_hash(nested) # => { "a.b.c" => 1, "x" => 2 }
