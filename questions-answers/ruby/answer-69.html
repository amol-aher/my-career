Question 69: What are frozen objects? What does Object#freeze do?

Concept

freeze prevents further modifications to an object. It sets the frozen flag; subsequent mutating calls raise a RuntimeError.

Optimal answer (concise)

Calling freeze on an object stops mutations; useful to enforce immutability and thread-safety for shared objects.

Subquestions & answers

  • Transitive freeze? — freeze is not deep by default; nested objects must be frozen individually.
  • Frozen string literal pragma: # frozen_string_literal: true makes string literals frozen at parse time.

Example

CONFIG = { host: 'x' }.freeze
CONFIG[:host] = 'y' # => works unless nested objects are frozen; freeze doesn't deep-freeze by default

Best practices / Pitfalls

  • Deep-freeze if necessary for complex structures; document frozen behavior to avoid surprises.
