Question 74: How do symbols help with memory optimization?

Concept

Symbols are immutable and reused (interned). Unlike strings, they don't allocate new objects each time, which reduces memory usage when the same identifier is repeated often.

Optimal answer (concise)

Symbols save memory and comparison cost since they're interned. Use them for identifiers/keys. Modern Ruby also has symbol GC.

Subquestions & answers

  • Comparison speed? — Symbols compare by identity, so it's faster than string comparison.
  • Risk? — Avoid creating many dynamic symbols in old Ruby versions (before symbol GC).
