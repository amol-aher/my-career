Question 158: Implement a rate-limited worker queue (allow X jobs per second) with multiple threads.

Concept

Rate limiting can be implemented with a token bucket or sleep logic to ensure only X jobs are processed per second across workers.

Optimal answer (concise)

Implement a shared token bucket replenished periodically; workers consume tokens before processing jobs.

Code

require 'thread'

class RateLimiter
  def initialize(rate_per_sec)
    @rate = rate_per_sec
    @tokens = rate_per_sec
    @mutex = Mutex.new
    Thread.new do
      loop do
        sleep 1
        @mutex.synchronize { @tokens = @rate }
      end
    end
  end

  def allow?
    @mutex.synchronize do
      if @tokens > 0
        @tokens -= 1
        true
      else
        false
      end
    end
  end
end

end
