Question 99: What is a thread? How does a thread differ from a process?

Concept

A thread is an execution context within a process that shares memory with other threads in the same process. A process has its own memory space and system resources.

Optimal answer (concise)

Threads are lightweight and share memory; processes are isolated and heavier. Threads allow shared-state concurrency; processes provide isolation and fault-tolerance.

Subquestions & answers

  • IPC: processes communicate via IPC (pipes, sockets, shared memory), threads communicate via shared memory.
  • Failure isolation: process crash doesn't necessarily kill others; thread crash may bring down the process.

Best practices

  • Use processes for isolation and CPU-bound parallelism on MRI; threads for IO-bound concurrency and when sharing memory is desired.
