Question 95: Implement a custom map method.

Concept

Enumerable#map transforms elements by applying a block and returning a new array. A custom implementation yields each element to the block and collects results.

Optimal answer (concise)

Iterate over the enumerable, yield to the block, and push results into an array.

Code

module Enumerable
  def my_map
    result = []
    each do |el|
      result << yield(el)
    end
    result
  end
end

[1,2,3].my_map { |x| x*2 } # => [2,4,6]

Notes

Handle cases when no block is given by returning an Enumerator.
