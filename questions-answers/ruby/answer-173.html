Question 173: Implement an asynchronous HTTP fetcher using Fibers or async/nio4r (production recommendation)

Concept

For production, use battle-tested async HTTP clients that integrate with the Ruby scheduler (e.g., httpx, async/http). They handle connection pooling, timeouts, TLS, and concurrency correctly.

Optimal answer (concise)

Use httpx (or async) which supports the Ruby fiber scheduler, provides HTTP/2, timeouts, and robust error handling. Avoid homegrown non-blocking implementations in production.

Example (httpx usage)

# gem 'httpx'
require 'httpx'
HTTPX.get('https://example.com').to_s

Notes

Leverage existing libraries for security, correctness, and performance. Configure timeouts, connection pools, and integrate with your fiber scheduler when using async IO.
