Question 100: How do you create and start a thread in Ruby? Show the basic syntax.

Concept

Create threads with Thread.new or Thread.start; they start executing the block immediately.

Optimal answer (concise)

Thread.new { ... } returns a Thread object; call join to wait for completion.

Code

t = Thread.new do
  puts 'hello from thread'
  sleep 1
  puts 'thread done'
end
t.join

# multiple threads
threads = 5.times.map do |i|
  Thread.new { puts i; sleep rand(0.1) }
end
threads.each(&:join)
