Question 97: Given a list of numbers, return only the prime numbers.

Concept

Primality can be checked by trial division up to sqrt(n). For many numbers, optimized checks or sieve algorithms are preferable.

Optimal answer (concise)

Filter numbers by primality test: for n >= 2, check divisibility from 2..sqrt(n).

Code

def primes(arr)
  arr.select do |n|
    next false if n < 2
    i = 2
    limit = Math.sqrt(n).to_i
    is_prime = true
    while i <= limit
      if n % i == 0
        is_prime = false
        break
      end
      i += 1
    end
    is_prime
  end
end

primes([1,2,3,4,5,16,17]) # => [2,3,5,17]

Notes

For large ranges, use Sieve of Eratosthenes for efficiency.
