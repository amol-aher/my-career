Question 75: When would you prefer Struct vs Class?

Concept

Struct is a quick way to define simple classes with attributes, automatically creating initializer, accessors, and equality methods.

Optimal answer (concise)

Use Struct for lightweight data objects without complex behavior. Use Class when you need more control, custom logic, or inheritance.

Example

Point = Struct.new(:x, :y)
p = Point.new(1,2)
p.x # => 1

Best practices

  • For clarity in larger systems, prefer explicit classes with attr_accessor.
