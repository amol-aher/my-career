Question 38: Have you used benchmarking tools in Ruby to measure performance?

Concept

Benchmarking measures code performance. Ruby has stdlib Benchmark and other tools (benchmark-ips, ruby-prof) for micro and macro profiling.

Optimal answer (concise)

Yes — use Benchmark/Benchmark.ips for microbenchmarks and ruby-prof, stackprof, or async-profiler (for JRuby) for profiling CPU and memory.

Subquestions & answers

  • Benchmark vs Benchmark.ips: Benchmark.ips measures iterations per second and is useful for comparing implementations.
  • Profilers: ruby-prof and stackprof for sampling/profiling; async-profiler for JVM/JRuby.
  • Noise: run benchmarks in isolated environments and warm up the VM.

Example

require 'benchmark/ips'
Benchmark.ips do |x|
  x.report('map') { (1..100).map { |i| i * 2 } }
  x.report('each') { (1..100).each { |i| i * 2 } }
  x.compare!
end

Best practices / Pitfalls

  • Warm up the VM, minimize background noise, and run multiple iterations.
  • Use realistic inputs that represent production workloads.
