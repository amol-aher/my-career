Question 55: What are some common Array and Hash methods you’ve used?

Concept

Ruby provides rich methods for collections.

Optimal answer (concise)

  • Array: map, each, select, reject, reduce, flatten, uniq.
  • Hash: keys, values, merge, transform_values, each, dig.

Example

arr = [1,2,3,3]
arr.uniq.map { |x| x*2 } # => [2,4,6]

h = {a: 1, b: 2}
h.merge(c: 3) # => {a:1,b:2,c:3}
