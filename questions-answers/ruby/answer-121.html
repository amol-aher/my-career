Question 121: How do you use ConditionVariable with Mutex? Give a use case.

Concept

ConditionVariable allows threads to wait (sleep) for a condition while releasing a Mutex and be signaled by other threads when the condition holds. It's used for coordination (producer/consumer, wait/notify).

Optimal answer (concise)

Use a Mutex to protect shared state and a ConditionVariable to wait for changes. Call cond.wait(mutex) to wait and cond.signal or cond.broadcast to wake waiters.

Example

mutex = Mutex.new
cond = ConditionVariable.new
queue = []

producer = Thread.new do
  5.times do |i|
    mutex.synchronize do
      queue << i
      cond.signal
    end
    sleep 0.1
  end
end

consumer = Thread.new do
  loop do
    item = nil
    mutex.synchronize do
      cond.wait(mutex) while queue.empty?
      item = queue.shift
    end
    break if item.nil?
    puts "consumed \#{item}"
  end
end

producer.join
# push nil to stop consumer
mutex.synchronize { queue << nil; cond.signal }
consumer.join

Best practices

  • Always wait in a loop checking the condition to avoid spurious wakeups.
  • Keep mutex-held sections short to minimize contention.
