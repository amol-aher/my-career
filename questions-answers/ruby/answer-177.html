Question 177: Write tests that reliably reproduce a race condition, then fix the underlying code. (Advanced: include CI strategies)

Concept

Include race-detection tests in CI with stress runs, flakiness detection, and optional gated nightly jobs. Use tagging to run heavy concurrency tests outside fast unit suites.

Optimal answer (concise)

Add deterministic unit tests plus randomized stress tests to CI pipelines (nightly or on-demand). Fail fast for reproducible races and track flaky test trends to prioritize fixes.

CI strategy

  1. Fast unit tests in every PR.
  2. Concurrency stress tests on merge or nightly runners.
  3. Record and upload logs/heap dumps when tests fail for analysis.

Notes

Keep CI cost under control by running heavy tests selectively and adding retries with investigation for flaky failures.
