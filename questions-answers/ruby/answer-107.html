Question 107: What does Thread#kill / Thread#terminate do? Why is it dangerous?

Concept

Thread#kill (alias terminate) stops a thread immediately. It can leave shared resources in inconsistent states.

Optimal answer (concise)

Thread#kill abruptly ends a thread, bypassing ensure blocks. It's dangerous because it can corrupt program state. Prefer cooperative cancellation.

Example

t = Thread.new { begin; sleep; ensure; puts 'cleanup'; end }
t.kill # ensure may be skipped

Best practices

  • Prefer signaling threads to exit gracefully (flags, queues) instead of kill.
