Question 46: How are symbols different from strings in Ruby?

Concept

Symbols are immutable, interned identifiers — a single symbol object exists per name. Strings are mutable (unless frozen) and represent textual data.

Optimal answer (concise)

Use symbols for identifiers and keys (e.g., hash keys) and strings for data manipulated or read from IO. Symbols historically saved allocations; modern Ruby has symbol GC which reduces symbol memory concerns.

Subquestions & answers

  • Mutability: Strings can be mutated; symbols cannot.
  • Memory: Symbols are stored in symbol table; modern Ruby supports symbol GC but avoid creating symbols from untrusted or unbounded input.
  • Conversion: Use to_sym/to_s to convert.

Example

h = { name: 'Alice', 'role' => 'admin' }
h[:name] # => 'Alice'
'role'.to_sym # => :role

Best practices / Pitfalls

  • Avoid creating symbols from user input repeatedly (may create many symbols historically; symbol GC mitigates but still be cautious).
