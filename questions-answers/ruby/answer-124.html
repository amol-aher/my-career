Question 124: What are NonBlocking vs blocking operations? Give examples in Ruby.

Concept

Blocking operations wait until completion and block the current thread/fiber; non-blocking operations return immediately and require polling/callbacks or use async APIs to be awaited later.

Optimal answer (concise)

Blocking: File.read, sleep, synchronous Net::HTTP. Non-blocking: IO#read_nonblock, async HTTP clients integrated with fiber schedulers.

Examples

# blocking
data = TCPSocket.open(host, port).read

# non-blocking
sock = TCPSocket.new(host, port)
sock.read_nonblock(1024) rescue IO::WaitReadable
# use IO.select or event loop to wait for readiness

Best practices

  • Prefer non-blocking or fiber-aware IO in high-concurrency servers to avoid tying up threads.
