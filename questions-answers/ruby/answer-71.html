Question 71: What’s the difference between map and collect? Between detect and find?

Concept

Ruby's Enumerable provides aliases for developer convenience. map and collect are the same, as are detect and find.

Optimal answer (concise)

map and collect are identical — they transform each element. detect and find are also identical — they return the first element matching a condition.

Example

[1,2,3].map { |x| x*2 }      # => [2,4,6]
[1,2,3].collect { |x| x*2 }  # => [2,4,6]

[1,2,3].find { |x| x.even? }   # => 2
[1,2,3].detect { |x| x.even? } # => 2

Best practices / Pitfalls

  • Use map and find for consistency — they're more common in community style.
