Question 96: Build a simple DSL using Ruby blocks.

Concept

Ruby's blocks and instance_eval make building internal DSLs natural. DSLs often create reader-friendly configuration or domain-specific declarations.

Optimal answer (concise)

Use a builder object and instance_eval to interpret nested blocks as DSL statements.

Code

class HTMLBuilder
  def initialize; @out = '' end
  def tag(name, content = nil, &blk)
    @out << "<\#{name}>"
    if blk
      instance_eval(&blk)
    else
      @out << content.to_s
    end
    @out << "</\#{name}>"
  end
  def text(t); @out << t end
  def to_s; @out end
end

html = HTMLBuilder.new
html.tag('p') { text 'Hello' }
puts html.to_s # => 
Hello

Notes

Keep DSLs small and predictable; avoid eval of untrusted input.
