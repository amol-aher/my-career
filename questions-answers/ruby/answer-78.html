Question 78: How do define_method and class_eval work?

Concept

define_method defines methods dynamically with a block. class_eval evaluates code in class context, useful for metaprogramming.

Optimal answer (concise)

define_method adds instance methods programmatically. class_eval executes a block/string as if written inside the class. Both are metaprogramming tools.

Example

class C
  [:a, :b].each do |m|
    define_method(m) { puts "method #{m}" }
  end
end

class D
end
D.class_eval { def hi; "hello"; end }

Best practices

  • Prefer define_method over eval of strings for safety.
