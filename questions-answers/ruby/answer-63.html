Question 63: What are mixins? How do you use modules in Ruby?

Concept

Mixins are modules that add shared behavior to classes via include (instance methods) or extend (class/singleton methods). They're a primary mechanism for code reuse in Ruby.

Optimal answer (concise)

Define reusable methods in modules and include them into classes to add instance methods, or extend to add methods to a single object or class.

Subquestions & answers

  • include vs extend: include mixes in instance methods; extend adds methods to the receiver (class or instance).
  • prepend: inserts module before the class in the method lookup chain, useful to override behavior.

Example

module Loggable
  def log(msg); puts "[\#{self.class}] \#{msg}" end
end

class Svc
  include Loggable
end

Svc.new.log('hi') # => [Svc] hi

Best practices / Pitfalls

  • Keep modules focused; avoid modules that carry too many responsibilities (God modules).
