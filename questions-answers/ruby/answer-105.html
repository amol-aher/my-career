Question 105: How do Mutex and Monitor work in Ruby? When would you use each?

Concept

Mutex is a mutual exclusion lock ensuring only one thread enters a section. Monitor is like a re-entrant Mutex with higher-level abstraction.

Optimal answer (concise)

Use Mutex for basic synchronization. Use Monitor when you need re-entrant locking and condition variables for complex coordination.

Example

mutex = Mutex.new
mutex.synchronize { puts 'locked once' }

require 'monitor'
m = Monitor.new
m.synchronize do
  m.synchronize { puts 'reentrant lock' }
end

Best practices

  • Prefer Mutex for simplicity unless re-entrancy or Monitor mixin features are needed.
