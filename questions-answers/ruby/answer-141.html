Question 141: Explain the semantics of ObjectSpace and GC operations while threads are running. What should you be careful about?

Concept

ObjectSpace allows introspection of live Ruby objects. GC operations (mark, sweep, compact) can run while threads are active, but under MRI, the GVL ensures only one thread runs Ruby code at a time during GC.

Optimal answer (concise)

ObjectSpace enumerates live objects but is slow and can interfere with GC. Use cautiously in production. Be careful with performance overhead, memory pressure, and GC pauses. Avoid calling ObjectSpace in high-concurrency paths.

Subquestions & answers

  • Thread-safety: ObjectSpace is thread-safe under GVL, but iteration can be expensive.
  • Use cases: debugging, leak detection, metrics collection.

Example

ObjectSpace.each_object(String).take(5).each { |s| p s }

Best practices

  • Use ObjectSpace only in diagnostics/debugging tools, not hot paths.
  • For memory monitoring, prefer built-in GC::Profiler or metrics gems.
