Question 129: What is starvation in concurrent systems, and how might it show up in Ruby programs?

Concept

Starvation occurs when a thread or task never gets CPU or resources because others monopolize resources. It leads to unserved tasks and unfairness.

Optimal answer (concise)

Starvation can appear as certain jobs never being processed because other long-running tasks hold locks or thread pools are exhausted by high-priority work. Mitigate with fair queues, timeouts, and bounded work-stealing.

Subquestions & answers

  • Symptoms: growing queue for some job types, no progress despite CPU availability.
  • Mitigations: use prioritization with aging, fairness in schedulers, chunk long tasks, or use multiple queues.

Best practices

  • Monitor queue lengths and processing latency by job type to detect starvation early.
