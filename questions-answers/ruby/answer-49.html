Question 49: How do you define a method in Ruby?

Concept

Methods are defined using def and can be instance methods, class methods (singleton methods), or defined dynamically with define_method.

Optimal answer (concise)

Use def name(args) ... end for instance methods; for class methods, use def self.name or define on singleton class.

Subquestions & answers

  • Default args: def f(a=1).
  • Splat and keyword args: *args, **kwargs supported.
  • Dynamic methods: define_method creates methods at runtime.

Example

class C
  def instance_method(a, b=2)
    a + b
  end

  def self.class_method(x)
    x * 2
  end

  define_method(:dynamic) do |v|
    v.upcase
  end
end

Best practices / Pitfalls

  • Prefer explicit method definitions for readability; use dynamic methods sparingly.
