Question 143: What are the implications of using native extensions (C extensions) with threads in MRI?

Concept

C extensions can block the GVL, preventing other threads from executing Ruby code. Extensions should release the GVL during long-running or blocking operations.

Optimal answer (concise)

Native extensions may block concurrency unless they release the GVL. Use rb_thread_call_without_gvl to release the lock during heavy C work. Otherwise, they can starve other threads and increase latency.

Subquestions & answers

  • Thread safety: extensions must be thread-safe when releasing the GVL.
  • Best practice: release GVL around blocking IO or CPU-heavy loops.

Best practices

  • Audit extensions for GVL usage; prefer libraries that release GVL when appropriate.
