Question 155: Implement a thread-safe counter (increment/decrement) without using Mutex (hint: use stdlib atomics or other mechanisms).

Concept

Use atomic primitives from concurrent-ruby or stdlib to achieve atomic increments without Mutex.

Optimal answer (concise)

Use Concurrent::AtomicFixnum from concurrent-ruby for lock-free atomic operations.

Code

require 'concurrent-ruby'

class AtomicCounter
  def initialize(val = 0)
    @a = Concurrent::AtomicFixnum.new(val)
  end

  def increment(n = 1)
    @a.increment(n)
  end

  def decrement(n = 1)
    @a.decrement(n)
  end

  def value
    @a.value
  end
end

c = AtomicCounter.new
threads = 10.times.map { Thread.new { 1000.times { c.increment } } }
threads.each(&:join)
puts c.value # => 10000

Best practices

  • Atomics are great for counters and simple coordination; use Mutex for complex invariants.
