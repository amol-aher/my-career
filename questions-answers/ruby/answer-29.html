Question 29: Have you used threads in your Ruby program? What kind of threads have you used?

Concept

Threads are units of concurrency. In Ruby, you can create threads for IO-bound or coordination tasks. Use thread pools and queues for stable concurrency patterns.

Optimal answer (concise)

Yes — used short-lived worker threads, thread pools (concurrent-ruby), and background scheduler threads for IO-bound tasks and orchestration. For CPU-bound tasks on MRI, prefer processes.

Subquestions & answers

  • Thread pools: use concurrent-ruby or custom pools with Queue.
  • Joining: use Thread#join to wait for completion.

Example

require 'thread'
queue = Queue.new
workers = Array.new(5) do
  Thread.new do
    loop do
      job = queue.pop
      break if job == :stop
      job.call
    end
  end
end
queue << -> { puts 'work' }
5.times { queue << :stop }
workers.each(&:join)
