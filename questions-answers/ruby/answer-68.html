Question 68: Explain the difference between mutable and immutable objects in Ruby.

Concept

Mutable objects can change state after creation (e.g., String unless frozen). Immutable objects cannot be changed (frozen objects, symbols).

Optimal answer (concise)

Mutable: arrays, strings (by default); immutable: symbols and frozen objects. Use freeze to make objects immutable.

Subquestions & answers

  • Why immutability helps: thread-safety, caching, avoiding unexpected changes.
  • How to freeze: obj.freeze. Be aware frozen? to check.

Example

s = 'hi'
s.freeze
s << '!' # => RuntimeError: can't modify frozen String

Best practices / Pitfalls

  • Use frozen string literals (pragma) and freeze shared constants to avoid mutation bugs.
