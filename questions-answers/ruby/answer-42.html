Question 42: How is a proc different from a lambda?

Concept

They are both instances of Proc but differ semantically: arity checking and return behavior.

Optimal answer (concise)

Lambda enforces argument counts and treats return as local to the lambda. Proc is lenient with arguments and a return inside a Proc attempts to return from the surrounding method.

Subquestions & answers

  • Creation: ->(x){...} or lambda { |x| ... } vs proc { |x| ... } or Proc.new { |x| ... }.
  • Class? — Both are Proc instances; use lambda? to check if it's a lambda.

Example

l = lambda { |x| x }
p = proc { |x| x }

l.lambda? # => true
p.lambda? # => false

Best practices

  • Document expectations when accepting callables (lambda vs proc).
