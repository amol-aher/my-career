Question 64: What’s the difference between include, extend, and prepend?

Concept

These module operations affect the method lookup chain differently.

Optimal answer (concise)

include puts module between the class and its ancestors (instance methods added). extend adds methods to the receiver's singleton class. prepend inserts module before the class — its methods take precedence over class methods.

Subquestions & answers

  • Use prepend for: wrapping or modifying behavior while still calling super.
  • extend use case: adding class-level helpers or per-instance behavior.

Example

module M; def hello; 'm' end end
class A; include M; def hello; 'a' end end
A.new.hello # => 'a' (class wins)

class B; prepend M; def hello; 'b' end end
B.new.hello # => 'm' (module wins)

Best practices / Pitfalls

  • Use prepend cautiously as it changes method precedence and can surprise maintainers.
