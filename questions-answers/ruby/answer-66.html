Question 66: What’s duck typing in Ruby?

Concept

Duck typing means an object's suitability is determined by the presence of methods and behavior rather than its class. "If it quacks like a duck..."

Optimal answer (concise)

Favor interfaces (respond_to?) and polymorphism over explicit type checks. Write code that operates on objects with required methods.

Subquestions & answers

  • When to check types: Validate inputs at public boundaries; use respond_to? or duck-typed tests for behavior.
  • Testing: use test doubles that implement expected methods.

Example

def quack(thing)
  thing.quack if thing.respond_to?(:quack)
end

Best practices / Pitfalls

  • Document expected behavior for public APIs; don't overuse respond_to? leading to fragile code.
