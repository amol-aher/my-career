Question 148: Discuss how to implement backpressure and flow control across threaded pipelines in Ruby.

Concept

Backpressure ensures producers don't overwhelm consumers. Flow control coordinates producer/consumer rates.

Optimal answer (concise)

Use SizedQueue between producer/consumer threads. Producers block when queue is full, preventing overload. Tune queue sizes based on workload and memory.

Example

queue = SizedQueue.new(10)
producer = Thread.new do
  loop { queue.push(work) } # blocks if full
end
consumer = Thread.new do
  loop { process(queue.pop) }
end

Best practices

  • Use timeouts and error handling. Monitor queue length as a signal of backpressure.
