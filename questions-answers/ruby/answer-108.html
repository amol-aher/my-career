Question 108: What are Thread.current and thread-local variables? How do you set/get them?

Concept

Thread.current gives the currently executing thread. Thread-local variables are stored per-thread in a hash-like structure.

Optimal answer (concise)

Use Thread.current[:key] = value to set and Thread.current[:key] to get. Each thread has its own storage.

Example

Thread.new do
  Thread.current[:id] = 123
  puts Thread.current[:id] # => 123
end.join

Best practices

  • Thread-local vars are useful for request context (e.g., current_user in web apps), but clear them to avoid leaks in thread pools.
