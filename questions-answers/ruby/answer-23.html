Question 23: If your object has five attributes and you want to apply two more attributes using decorators, will it affect all the objects or just that one?

Concept

Decorators applied to a single object (wrapper or singleton methods via extend) affect only that instance. Changing the class or including a module into the class affects all instances.

Optimal answer (concise)

Applying a decorator as a wrapper or using object.extend affects only that object. Including a module into the class affects all instances.

Example

u = User.new
module Extra; def vip?; true end; end
u.extend(Extra) # only u has vip?
v = User.new
v.respond_to?(:vip?) # false

Best practices / Pitfalls

  • Prefer explicit wrappers for per-instance behavior to avoid surprising global changes.
