Question 130: How would you design a thread pool in Ruby? What factors do you tune?

Concept

A thread pool limits concurrency by reusing a fixed number of threads to execute tasks from a job queue. Key components: job queue, worker threads, shutdown handling, and backpressure.

Optimal answer (concise)

Design a pool with a SizedQueue for jobs, a fixed set of worker threads consuming jobs, and graceful shutdown. Tune pool size, queue capacity, and worker timeouts based on CPU/IO characteristics and memory.

Example

class ThreadPool
  def initialize(size, queue_size = 100)
    @queue = SizedQueue.new(queue_size)
    @workers = size.times.map do
      Thread.new do
        loop do
          job = @queue.pop
          break if job == :shutdown
          job.call
        end
      end
    end
  end

  def schedule(&block)
    @queue.push(block)
  end

  def shutdown
    @workers.size.times { @queue.push(:shutdown) }
    @workers.each(&:join)
  end
end

Factors to tune

  • Pool size: number of threads relative to CPU cores and IO blocking behavior.
  • Queue size: backpressure and memory tradeoffs.
  • Worker timeouts: prevent stuck threads from consuming capacity.
