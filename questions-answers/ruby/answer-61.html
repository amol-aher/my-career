Question 61: What’s the difference between self inside a class vs inside an instance method?

Concept

self refers to the current object context. Inside an instance method, self is the instance. Inside the class body (top-level of class), self is the class object (singleton class context when inside class << self).

Optimal answer (concise)

In instance methods, self is the object instance; in the class body, self is the class (so defining def self.foo creates a class method).

Subquestions & answers

  • Inside class << self: you are in the singleton class — methods defined there are class methods.
  • Inside class methods: self remains the class object.

Example

class C
  puts self # => C (during class definition)

  def instance_name; self end
  def self.describe; self.to_s end
end

c = C.new
c.instance_name # => #<C:0x...>
C.describe      # => "C"

Best practices / Pitfalls

  • Be explicit when defining class methods: def self.method or class << self for clarity.
