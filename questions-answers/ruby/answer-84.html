Question 84: What is the difference between load, require, and autoload?

Concept

All are ways to load code. require loads a file once per process. load reloads every time. autoload registers a file to be loaded automatically when a specified constant is first accessed (deprecated in some contexts).

Optimal answer (concise)

Use require for libraries, load for forced reloads, and autoload for lazy loading constants (though modern code often prefers explicit requires or Zeitwerk-style autoloading).

Subquestions & answers

  • Zetiework: Rails uses Zeitwerk for autoloading in development — it maps constants to files.
  • Thread-safety: autoload historically had thread-safety issues; prefer modern loaders that are thread-safe.

Example

autoload :MyService, './my_service'  # loads file when MyService constant is first referenced
require './lib/foo'                   # loads immediately

Best practices / Pitfalls

  • Prefer project-level autoloaders (Zeitwerk) or explicit requires; avoid ad-hoc autoload in multi-threaded environments.
