Question 120: Explain Queue and SizedQueue in Ruby. How are they used for producer/consumer patterns?

Concept

Queue is a thread-safe FIFO queue. SizedQueue adds a maximum size and blocks producers when full, providing backpressure.

Optimal answer (concise)

Use Queue for simple producer/consumer communication. Use SizedQueue to limit in-flight jobs and provide natural backpressure to producers.

Example

queue = SizedQueue.new(10) # max 10 items
producer = Thread.new do
  100.times do |i|
    queue.push(i) # blocks when queue full
  end
  queue.push(:done)
end

consumer = Thread.new do
  loop do
    item = queue.pop
    break if item == :done
    process(item)
  end
end

[producer, consumer].each(&:join)

Best practices

  • Use SizedQueue to avoid unbounded memory growth; ensure consumers finish or use sentinel values for graceful shutdown.
