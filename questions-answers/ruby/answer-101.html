Question 101: How do you wait for a thread to finish (join) in Ruby?

Concept

Thread#join blocks the calling thread until the target thread finishes execution. It's how you synchronize threads in Ruby.

Optimal answer (concise)

Call thread.join to wait for it to complete. You can also pass a timeout: thread.join(2).

Example

t = Thread.new { sleep 1; puts 'done' }
t.join # main thread waits
puts 'after join'

Best practices

  • Always join worker threads before program exit to avoid premature termination.
  • Consider Thread#value to both wait and get return value.
