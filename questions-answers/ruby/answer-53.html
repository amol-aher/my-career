Question 53: How do arrays differ from hashes in Ruby?

Concept

Arrays are ordered collections indexed by integer positions. Hashes are key-value mappings with arbitrary keys.

Optimal answer (concise)

Arrays use integer indices, preserve insertion order, and are good for lists. Hashes map keys (any object implementing hash & eql?) to values, and preserve insertion order since Ruby 1.9.

Subquestions & answers

  • Performance? — Arrays: O(1) lookup by index. Hashes: O(1) average for key lookup.
  • Default values? — Hashes support default values with Hash.new.

Example

arr = [10, 20, 30]
h = {a: 1, b: 2}
arr[1]  # => 20
h[:a]   # => 1
