Question 113: What is cooperative vs preemptive multitasking? Which model do Fibers use?

Concept

Cooperative multitasking requires tasks to yield control voluntarily. Preemptive multitasking allows the scheduler to interrupt tasks arbitrarily. Fibers use cooperative multitasking.

Optimal answer (concise)

Fibers are cooperative: they run until they yield or finish. Threads (OS-level) are usually preemptive (scheduler can interrupt). Use fibers for deterministic control and lower overhead for async IO.

Subquestions & answers

  • Implication: fiber code must yield, otherwise it can starve others in the same scheduler.
  • Use cases: Fibers are ideal for implementing async IO libraries and coroutines.

Best practices

  • Ensure library code using fibers yields on IO or long computations; otherwise cooperative model can hang the system.
