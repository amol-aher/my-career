Question 119: What are Thread.report_on_exception and Thread.abort_on_exception? How do they behave?

Concept

These settings control global/thread-level behavior when an exception escapes a thread.

Optimal answer (concise)

Thread.abort_on_exception = true causes the main thread to be terminated when any thread raises an unhandled exception. Thread.report_on_exception = true prints backtraces for unhandled exceptions in threads without aborting.

Subquestions & answers

  • Thread-level: you can set t.abort_on_exception = true per thread.
  • Behavior: helpful in development to surface thread errors; production systems may prefer logging and controlled shutdown.

Example

Thread.abort_on_exception = true
Thread.new { raise 'boom' } # raises and aborts main process

Best practices

  • Use these flags in development/testing; in production, handle exceptions and log them with context.
