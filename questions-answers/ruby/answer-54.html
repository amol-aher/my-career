Question 54: How do you iterate over an array?

Concept

Iteration is commonly done with each, but Ruby provides many enumeration methods.

Optimal answer (concise)

Use array.each with a block for simple iteration, or map, select, for loop when appropriate.

Subquestions & answers

  • each_with_index? — Provides index during iteration.
  • Enumerator? — If no block is given, each returns an Enumerator.

Example

arr = [1,2,3]
arr.each { |x| puts x }
arr.each_with_index { |x,i| puts "\#{i}: \#{x}" }
