Question 60: What’s the role of initialize in a Ruby class?

Concept

initialize is a special method called when new is invoked on a class. It sets up the object (constructor).

Optimal answer (concise)

initialize is the constructor, used to set initial state of objects.

Subquestions & answers

  • Can you override initialize? — Yes, by defining your own method; don't call it directly, use new.
  • Arguments? — Can accept arguments and defaults, passed through new.

Example

class Point
  attr_reader :x, :y
  def initialize(x, y)
    @x, @y = x, y
  end
end
p = Point.new(3, 4)
