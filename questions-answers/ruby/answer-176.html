Question 176: Implement an asynchronous HTTP fetcher using Fibers or async/nio4r (deep dive: connection pooling and timeouts)

Concept

Connection pooling and timeouts are critical for production HTTP clients. Async libraries typically manage pools and provide per-request timeouts and global limits.

Optimal answer (concise)

Use httpx or async/http which support pooling, keep-alive, timeouts, TLS, and HTTP/2. Configure pool size, per-host limits, and built-in timeouts for robust behavior.

Configuration example (httpx)

require 'httpx'
client = HTTPX.plugin(:persistent).with(pool_size: 5, per_host: 2, connect_timeout: 5, response_timeout: 10)
resp = client.get('https://example.com')
puts resp.status, resp.to_s[0..200]

Notes

Implementing a custom pool is error-prone; prefer libraries that manage socket reuse and concurrency properly.
