Question 93: Implement a method to reverse a string without using built-in methods.

Concept

Reversing a string can be done by iterating characters from the end to the start and building a new string.

Optimal answer (concise)

Iterate indices from last to first and append characters to a result.

Code

def reverse_string(s)
  result = ''
  i = s.length - 1
  while i >= 0
    result << s[i]
    i -= 1
  end
  result
end

reverse_string('hello') # => 'olleh'

Notes

This approach uses indexing and concatenation; for unicode-aware reversal use codepoints.
