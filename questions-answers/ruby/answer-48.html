Question 48: What are Ruby’s truthy and falsy values?

Concept

In Ruby, only false and nil are falsy. Everything else (including 0, empty string, empty array) evaluates as truthy in boolean context.

Optimal answer (concise)

Falsy: false, nil. Truthy: everything else (0, '', [], {}, etc.).

Subquestions & answers

  • Common gotcha: 0 is truthy (unlike in some languages).
  • Use in conditionals: check for nil? or emptiness when needed, not truthiness alone.

Example

if 0
  puts 'zero is truthy' # prints
end

if ''
  puts 'empty string is truthy' # prints
end

Best practices / Pitfalls

  • Be explicit when checking for presence: if value vs if value.nil? vs if value.present? (Rails).
