Question 106: What is a deadlock? How might a deadlock occur with mutexes?

Concept

A deadlock is a situation where two or more threads wait on resources held by each other, preventing progress.

Optimal answer (concise)

Deadlock occurs when threads acquire locks in inconsistent order. To avoid, acquire locks in consistent order or use try_lock with timeout.

Example

m1 = Mutex.new
m2 = Mutex.new

t1 = Thread.new do
  m1.synchronize do
    sleep 0.1
    m2.synchronize { puts 't1 done' }
  end
end

t2 = Thread.new do
  m2.synchronize do
    sleep 0.1
    m1.synchronize { puts 't2 done' }
  end
end

[t1, t2].each(&:join) # deadlock

Best practices

  • Always acquire locks in a consistent global order.
