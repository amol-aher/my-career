Question 36: What changes are needed in your code to integrate New Relic?

Concept

New Relic is an APM that instruments web apps to record transactions, errors, and performance metrics. Integration usually requires adding the New Relic agent and minor configuration.

Optimal answer (concise)

Add the New Relic gem, provide a configuration file or environment variables (license key, app name), and optionally add custom instrumentation for background jobs and critical code paths.

Subquestions & answers

  • Install: add gem 'newrelic_rpm' and run bundle install.
  • Configuration: use newrelic.yml or environment vars like NEW_RELIC_LICENSE_KEY.
  • Custom instrumentation: use NewRelic::Agent.add_custom_attributes or record_metric.

Example

# initializer/newrelic.rb
if ENV['NEW_RELIC_LICENSE_KEY']
  require 'newrelic_rpm'
  NewRelic::Agent.manual_start
end

# custom transaction
NewRelic::Agent.add_custom_attributes(user_id: current_user.id)

Best practices / Pitfalls

  • Avoid sending PII as custom attributes without masking.
  • Use sampling for high-throughput metrics to control cost.
