Question 73: How do enumerators work? What’s the benefit of lazy enumerators?

Concept

Enumerators encapsulate iteration. When a block isn't given, many methods return an Enumerator object. Lazy enumerators evaluate elements on demand.

Optimal answer (concise)

Enumerators allow external iteration and chaining. Lazy enumerators avoid creating intermediate collections and support infinite sequences by evaluating lazily.

Example

e = [1,2,3].map
e.each { |x| puts x }

lazy = (1..Float::INFINITY).lazy.map { |x| x*2 }.select(&:even?)
lazy.first(5) # => [2,4,6,8,10]

Best practices

  • Use lazy for large/infinite collections or expensive transformations.
