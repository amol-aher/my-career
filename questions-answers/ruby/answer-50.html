Question 50: Explain string interpolation in Ruby.

Concept

String interpolation embeds Ruby expressions inside double-quoted strings using \#{...}. The expression is evaluated and converted to string via to_s.

Optimal answer (concise)

Use "Hello \#{name}" to interpolate. Interpolation doesn't work in single-quoted strings (except escaped sequences).

Subquestions & answers

  • Performance: Interpolation creates temporary strings; beware in hot loops — consider other techniques or frozen strings.
  • Nil handling: \#{nil} => empty string.

Example

name = 'Alice'
"Hi \#{name.upcase}, time: \#{Time.now.strftime('%H:%M')}"

Best practices / Pitfalls

  • Avoid complex expressions inside interpolation when readability suffers; assign to variables first.
