Question 126: How do you safely stop a worker thread that is blocked on IO or sleeping?

Concept

Cooperative shutdown: signal the thread to stop and ensure it wakes if blocked (e.g., interruptible IO, closing the socket, using non-blocking IO with select, or using thread-safe flags).

Optimal answer (concise)

Use a shutdown flag and ensure blocked operations are interruptible (close socket, use IO#wait_readable with timeout, or use interruptible sleep). Avoid Thread.kill.

Example

stop = false
t = Thread.new do
  until stop
    begin
      data = socket.readpartial(4096) # can raise on socket close
      process(data)
    rescue EOFError, IOError
      break
    end
  end
end

# to stop:
stop = true
socket.close # this will unblock readpartial and let thread exit
t.join

Best practices

  • Design threads to be interruptible and handle exceptions from resource closure cleanly.
