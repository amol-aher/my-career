Question 18: Which one (private/protected) is available across instances?

Concept

Protected methods can be invoked across instances within the same class hierarchy; private methods cannot be called with an explicit receiver (hence not across instances).

Optimal answer (concise)

protected methods are available across instances of the same class/subclasses; private are not.

Example

class C
  protected
  def p; 'p' end
end
a, b = C.new, C.new
a.send(:p) # works if called within class context
