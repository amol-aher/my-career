Question 110: What is a Ruby Fiber? How does it differ from a Thread?

Concept

Fibers are lightweight, cooperatively scheduled units of execution. Threads are preemptively scheduled by OS/interpreter.

Optimal answer (concise)

Fibers run only when resumed explicitly (or via async scheduler). Threads can be preempted and run in background. Fibers are great for async IO; threads for parallelism (subject to GVL).

Example

f = Fiber.new do
  puts 'fiber start'
  Fiber.yield
  puts 'fiber resume'
end

f.resume
puts 'back in main'
f.resume

Best practices

  • Use fibers for async IO (Ruby 3 Fiber scheduler). Not suitable for CPU-heavy tasks.
