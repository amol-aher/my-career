Question 117: How would you parallelize a CPU-bound task in Ruby given MRI’s GVL?

Concept

Use processes (fork, parallel gem), native C extensions that release the GVL, or offload to external services to parallelize CPU-bound work on MRI.

Optimal answer (concise)

Spawn multiple worker processes (Process.fork or parallel gem's in_processes) or move compute to native extensions or external microservices to use multiple cores.

Example

# using parallel gem (processes)
require 'parallel'
Parallel.map([1,2,3,4], in_processes: 4) { |n| heavy_compute(n) }

Best practices

  • Manage process lifecycle (supervisor), and reconnect resources (DB) after fork.
