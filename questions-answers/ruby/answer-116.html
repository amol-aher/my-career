Question 116: When can Ruby threads actually run in parallel (true CPU-bound parallelism)?

Concept

True parallelism depends on interpreter: MRI restricts parallel Ruby bytecode via GVL; JRuby and other implementations do not, and native extensions in MRI can release the GVL.

Optimal answer (concise)

Use JRuby or TruffleRuby for true parallel Ruby execution. In MRI, parallelism is possible if native C extensions release the GVL or for blocking IO handled by the OS.

Subquestions & answers

  • Native extensions: libraries like OpenSSL or JSON may release the GVL for heavy work.
  • Process-based parallelism: fork/spawn separate processes to utilize all cores on MRI.

Best practices

  • Select runtime based on need for true parallelism; avoid relying on thread parallelism on MRI for CPU-bound workloads.
