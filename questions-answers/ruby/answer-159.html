Question 159: Show how to use IO.select (or Process.wait) to concurrently wait for multiple IO streams.

Concept

IO.select allows waiting on multiple IO descriptors for readiness; Process.wait watches child processes' exit status.

Optimal answer (concise)

Use IO.select with arrays of readable/writable sockets to implement event loops; use Process.wait to reap child processes and avoid zombies.

Code

r1, w1 = IO.pipe
r2, w2 = IO.pipe

w1.puts 'hello'
w2.puts 'world'

ready = IO.select([r1, r2], nil, nil, 1)
if ready
  ready[0].each do |r|
    puts r.gets.chomp
  end
end

# Process.wait example
pid = fork { exit 0 }
Process.wait(pid) # reaps child

Best practices

  • Use non-blocking reads with read_nonblock when integrating with select-based loops to avoid blocking on read.
