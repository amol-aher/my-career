Question 79: What’s the difference between send and public_send?

Concept

send allows calling any method (even private/protected). public_send restricts to public methods only.

Optimal answer (concise)

Use public_send when you want to respect visibility; send can bypass encapsulation (use with caution).

Example

class A
  private def secret; "shh"; end
end
a = A.new
# a.public_send(:secret) # => NoMethodError
a.send(:secret)           # => "shh"
