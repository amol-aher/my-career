Question 80: How do refinements differ from monkey patching?

Concept

Monkey patching reopens classes globally, affecting all code. Refinements allow scoped modifications that apply only within a lexical scope where using is called.

Optimal answer (concise)

Refinements provide localized monkey patches, activated with using. They prevent global pollution of classes.

Example

module StringRef
  refine String do
    def shout; upcase + "!" end
  end
end

using StringRef
"hi".shout # => "HI!"

Best practices

  • Use refinements for safer monkey patches, but remember they are limited in scope and may surprise maintainers.
