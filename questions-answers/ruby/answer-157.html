Question 157: Build a simple thread pool class (fixed-size) with job submission and graceful shutdown.

Concept

Thread pool manages a fixed set of worker threads consuming jobs from a queue. Implement job submission, shutdown, and optional timeouts.

Optimal answer (concise)

Use SizedQueue for job storage, spawn worker threads that pop jobs and execute them, and push shutdown tokens to stop workers gracefully.

Code

class SimpleThreadPool
  def initialize(size, queue_size = 100)
    @queue = SizedQueue.new(queue_size)
    @workers = size.times.map do
      Thread.new do
        loop do
          job = @queue.pop
          break if job == :shutdown
          begin
            job.call
          rescue => e
            warn "job error: \#{e.message}"
          end
        end
      end
    end
  end

  def schedule(&block)
    @queue.push(block)
  end

  def shutdown
    @workers.size.times { @queue.push(:shutdown) }
    @workers.each(&:join)
  end
end

Best practices

  • Expose monitoring hooks for queue length and worker health; consider timeouts and dead worker detection.
