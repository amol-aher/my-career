Question 163: Implement an asynchronous HTTP fetcher using Fibers or async/nio4r (or describe how to do it without external gems).

Concept

Async IO with fibers allows writing sequential-style code while performing non-blocking IO. Libraries like async and nio4r integrate with the fiber scheduler; without gems, use non-blocking sockets and IO.select.

Optimal answer (concise)

Prefer async gem for clarity. Without gems, create non-blocking sockets, register them with select, and resume fibers when sockets are readable/writable.

Example (simple select-based fetcher)

require 'socket'
require 'uri'

def fetch_nonblocking(url)
  uri = URI(url)
  port = uri.port || 80
  host = uri.host

  sock = TCPSocket.new(host, port)
  sock.setsockopt(Socket::IPPROTO_TCP, Socket::TCP_NODELAY, 1)
  sock.fcntl(Fcntl::F_SETFL, Fcntl::O_NONBLOCK)
rescue
  # fallback blocking
  return Net::HTTP.get(uri)
end

# Simplified: using blocking Net::HTTP is recommended unless using a library like async or nio4r

Notes

Implementing a robust async HTTP client is non-trivial; use vetted libraries like async, httpx, or nio4r unless you need custom behavior.
