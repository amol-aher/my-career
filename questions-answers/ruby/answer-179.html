Question 179: Write tests that reliably reproduce a race condition, then fix the underlying code. (Advanced: include mutation testing)

Concept

Mutation testing (e.g., mutmut) can help find weak tests that miss concurrency bugs. Combine mutation testing with deterministic concurrency tests to strengthen coverage.

Optimal answer (concise)

Use mutation testing to identify missing assertions in concurrency-related code paths. Strengthen tests, add explicit invariants, and re-run mutation to verify coverage.

Workflow

  1. Run mutation testing on critical modules.
  2. Identify mutants that escaped tests and add targeted concurrency tests.
  3. Repeat until mutation score is acceptable for critical areas.

Notes

Mutation testing is expensive; focus it on concurrency-critical modules and run selectively in CI.
