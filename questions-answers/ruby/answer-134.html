Question 134: Describe MRI’s Global VM Lock (GVL): history, purpose, implications, and current behavior.

Concept

GVL is MRI's global lock that serializes execution of Ruby bytecode, introduced to protect internal VM state and simplify C extension safety.

Optimal answer (concise)

GVL simplifies extension safety at the cost of parallel Ruby execution. MRI allows IO and certain C extensions to release the GVL, and Ruby core has evolved to reduce contention. For true parallelism, alternatives like JRuby exist.

Subquestions & answers

  • History: GVL existed early in Ruby to protect interpreter globals; YARV kept it but optimized around it.
  • Implications: concurrency for Ruby-level code is limited; must use processes or native code for parallel CPU work.

Best practices

  • Design around GVL limitations; prefer processes or GVL-free runtimes for parallel CPU workloads.
