Question 156: Implement a producer-consumer pipeline using Queue with multiple producers and consumers; add graceful shutdown.

Concept

Use a shared Queue for producers to push jobs and consumers to pop jobs. Use sentinel values or signals for graceful shutdown.

Optimal answer (concise)

Use SizedQueue for backpressure, push :shutdown sentinels equal to consumer count, and ensure consumers exit cleanly.

Code

require 'thread'

queue = SizedQueue.new(50)
consumers = 4.times.map do
  Thread.new do
    loop do
      job = queue.pop
      break if job == :shutdown
      job.call
    end
  end
end

producers = 2.times.map do
  Thread.new do
    100.times { |i| queue.push(-> { puts "job \#{i} by \#{Thread.current.object_id}" }) }
  end
end

producers.each(&:join)
# send shutdown signals
4.times { queue.push(:shutdown) }
consumers.each(&:join)

Best practices

  • Handle exceptions in workers, use retries or DLQ, and monitor queue length for backpressure metrics.
