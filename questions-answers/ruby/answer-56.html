Question 56: What’s the difference between map, each, and select?

Concept

These are Enumerable methods but serve different purposes.

Optimal answer (concise)

  • each: iterates, returns original collection.
  • map: transforms, returns new array of results.
  • select: filters, returns subset of elements for which block is truthy.

Example

arr = [1,2,3,4]
arr.each { |x| puts x }         # => [1,2,3,4]
arr.map { |x| x*2 }             # => [2,4,6,8]
arr.select { |x| x.even? }      # => [2,4]
