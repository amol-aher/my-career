Question 28: Have you ever used eval methods like instance_eval or class_eval?

Concept

instance_eval and class_eval evaluate code within the context of an object or class and are powerful metaprogramming tools for defining methods or accessing private state.

Optimal answer (concise)

Yes — used cautiously for dynamic method definitions or creating DSLs. Prefer define_method and controlled metaprogramming over arbitrary eval. Never eval untrusted input.

Subquestions & answers

  • instance_eval: runs block with self set to the receiver (useful for singletons).
  • class_eval: evaluates code in class/module context (useful for defining instance methods).
  • Security: don't evaluate untrusted code; consider alternatives.

Example

klass = Class.new
klass.class_eval do
  def greet; 'hello' end
end
k = klass.new
k.greet #=> 'hello'

Best practices / Pitfalls

  • Use metaprogramming sparingly; document intent and side-effects.
