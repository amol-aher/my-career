Question 94: Write a method that checks if a word is a palindrome.

Concept

A palindrome reads the same forwards and backwards; normalization (case, non-alphanumeric removal) is commonly applied.

Optimal answer (concise)

Normalize the string, then check if it equals its reverse (or compare characters from ends inward).

Code

def palindrome?(s)
  normalized = s.downcase.gsub(/[^a-z0-9]/i, '')
  normalized == normalized.reverse
end

palindrome?('A man, a plan, a canal: Panama') # => true

Notes

For large strings, compare characters without creating reversed copy to save memory.
