Question 111: How do you create and resume a Fiber?

Concept

Fibers are created with Fiber.new and resumed with resume. They can yield back control using Fiber.yield.

Optimal answer (concise)

Create a fiber with f = Fiber.new { ... }, start it with f.resume, and inside the fibre yield with Fiber.yield to return control to caller. Subsequent resume continues from the yield point.

Example

f = Fiber.new do |initial|
  puts "started with \#{initial}"
  val = Fiber.yield(:paused)
  puts "resumed with \#{val}"
  :done
end

p f.resume('hello')   # => :paused (and prints started...)
p f.resume('world')   # => :done (and prints resumed...)

Best practices

  • Use fibers for cooperative concurrency and make sure fiber code yields periodically when used in schedulers.
