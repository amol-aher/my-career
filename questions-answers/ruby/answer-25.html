Question 25: When you put any method inside the included block of a concern, will it be added as an instance method or class method?

Concept

The included block runs when the module is included. Methods defined inside the module body are instance methods. The included block is typically used to add callbacks, extend class methods, or set up scopes.

Optimal answer (concise)

Methods defined normally in the module become instance methods. The included block can call base.extend or use class_methods (ActiveSupport::Concern) to add class methods.

Example

module M
  extend ActiveSupport::Concern
  included do |base|
    base.scope :active, -> { where(active: true) }
  end

  def instance_method; 'instance' end

  class_methods do
    def class_method; 'class' end
  end
end

Best practices / Pitfalls

  • Use the class_methods block for clarity when adding class methods.
