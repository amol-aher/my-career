Question 133: How do Thread.handle_interrupt and Thread.interrupt interplay with long-running operations?

Concept

Thread.handle_interrupt and Thread.interrupt (Ruby 2.3+) provide a way to control how threads respond to interrupts, allowing safe interruption points for long-running operations.

Optimal answer (concise)

Use Thread.handle_interrupt to specify interruption behavior (:on, :off) and Thread.interrupt to raise an Interrupt in the target thread at a safe point. This provides cooperative interruption instead of abrupt kills.

Subquestions & answers

  • Use case: enable interruption around blocking IO or long loops to allow graceful shutdown.
  • Behavior: interrupts are delivered at defined interruption points, avoiding inconsistent state.

Example

t = Thread.new do
  Thread.handle_interrupt(ArgumentError => :on, wait: 0.1) do
    loop do
      # long-running work
      sleep 0.2
    end
  end
end

t.interrupt # requests an interrupt; thread will raise at interruptible points

Best practices / Pitfalls

  • Use interrupts for cooperative cancellation; avoid Thread.kill.
  • Test interrupt behavior under real workloads.
