Question 19: Can you write code to demonstrate private and protected methods in Ruby?

Concept

Showing examples clarifies the receiver rules of private and protected methods.

Optimal answer (concise)

The example below illustrates calling protected methods across instances and private methods only implicitly.

Example

class Person
  def initialize(name, age); @name = name; @age = age end

  def compare_age(other)
    if older_than?(other)
      "#{@name} is older than \#{other.name_for_compare(self)}"
    else
      "#{@name} is not older"
    end
  end

  protected
  def name_for_compare(caller)
    @name
  end

  private
  def older_than?(other)
    @age > other.age_private
  end

  protected
  def age_private; @age end

  # expose for demonstration only (not typical)
  def reveal_secret
    secret_message
  end

  private
  def secret_message; 'classified' end
end

a = Person.new('Alice', 30)
b = Person.new('Bob', 25)
puts a.compare_age(b) # uses protected method across instances
puts a.reveal_secret   # calls private method internally

Best practices

  • Use protected sparingly — it's a niche tool for intra-class instance interactions.
