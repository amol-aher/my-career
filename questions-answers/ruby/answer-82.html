Question 82: Explain Ruby’s object model (everything is an object, eigenclasses, singleton methods).

Concept

Ruby's object model treats classes and modules as objects. Each object can have a singleton class (eigenclass) that holds its singleton methods. Method lookup follows singleton class → class → included modules → superclass chain.

Optimal answer (concise)

Everything is an object in Ruby: classes are instances of Class; modules are instances of Module. Singleton methods are stored on the object's eigenclass which sits above the object's class in the method lookup chain.

Subquestions & answers

  • What is eigenclass? — A hidden anonymous class attached to an object that holds methods defined only on that object.
  • Singleton methods: defined using def obj.method or inside class << obj.

Example

o = Object.new
def o.hi; 'hello' end  # singleton method on o
class << o
  def bye; 'bye' end
end
o.hi  # => 'hello'
o.bye # => 'bye'

Best practices / Pitfalls

  • Use singleton methods for per-object behavior; avoid overusing as it complicates object structure.
