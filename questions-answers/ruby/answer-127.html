Question 127: How can select, IO#wait_readable, or IO.select be used for concurrency in Ruby?

Concept

select/wait_readable allow multiplexing IO on a single thread by waiting for readiness on multiple file descriptors, enabling event-driven concurrency.

Optimal answer (concise)

Use IO.select or IO#wait_readable to block until sockets are ready, process available sockets, and avoid blocking per-connection threads. This is the basis for event loops.

Example

sockets = [sock1, sock2]
ready = IO.select(sockets, nil, nil, timeout)
if ready
  readable = ready[0]
  readable.each { |sock| data = sock.read_nonblock(4096) rescue IO::WaitReadable; handle(data) }
end

Best practices

  • Combine with non-blocking IO and careful error handling for robust event loops.
