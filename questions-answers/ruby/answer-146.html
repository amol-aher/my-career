Question 146: Describe how to build deterministic tests for concurrent code. What techniques and libraries help?

Concept

Concurrent code is nondeterministic, but deterministic testing aims to control or simulate scheduling. Techniques: dependency injection of schedulers, fake clocks, controlling thread interleaving.

Optimal answer (concise)

Use deterministic schedulers, mocks, and tools like RSpec's time helpers or specialized concurrency testing libraries. Insert synchronization points or use model checking approaches.

Subquestions & answers

  • Techniques: use barriers/latches, test harnesses that control thread progress.
  • Libraries: rspec-retry, deterministic schedulers, custom wrappers for thread coordination.

Best practices

  • Design code to allow injection of schedulers/clocks for testability.
  • Write stress tests in addition to deterministic unit tests.
