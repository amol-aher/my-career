Question 77: How does method_missing work? What are the risks of using it?

Concept

method_missing is called when an undefined method is invoked. It's often used for dynamic APIs (ActiveRecord dynamic finders).

Optimal answer (concise)

Override method_missing to handle undefined methods dynamically. Always also override respond_to_missing?. Risks: performance cost, debugging difficulty, unexpected behavior.

Example

class Dyn
  def method_missing(name, *args)
    if name.to_s.start_with?("say_")
      puts name.to_s.sub("say_", "")
    else
      super
    end
  end
  def respond_to_missing?(name, inc_priv)
    name.to_s.start_with?("say_") || super
  end
end

Dyn.new.say_hello # => "hello"

Best practices

  • Always implement respond_to_missing?.
  • Prefer explicit methods or define_method for performance.
