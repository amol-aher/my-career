Question 152: What is the correctness definition for a concurrent data structure (e.g., linearizability)? How could you test for it in Ruby?

Concept

Linearizability means each operation appears to occur atomically at some point between its invocation and response, preserving real-time order and behaving like a sequential execution.

Optimal answer (concise)

Test linearizability by recording histories of concurrent operations (start/end timestamps, inputs, outputs) and checking if an equivalent sequential history exists that respects real-time ordering. Use tools or write validators to explore possible sequentializations.

Subquestions & answers

  • Testing approach: fuzz tests, record operation traces, and run a linearizability checker offline.
  • Tools: no mainstream Ruby linearizability checker, but you can implement history recording and use external validators or port a checker.
