Question 154: Write a Ruby program that spawns N threads to compute parts of an array sum and returns the total. Discuss thread-safety and correctness.

Concept

Partition work among N threads, each computes a partial sum, then combine results. Use thread-safe aggregation (Mutex, atomic) or collect partial results and sum in main thread.

Optimal answer (concise)

Use per-thread local sums to avoid contention, then sum them after joining threads. Avoid shared increments to a global counter without synchronization.

Code

def parallel_sum(arr, n_threads = 4)
  parts = arr.each_slice((arr.size / n_threads.to_f).ceil).to_a
  threads = parts.map do |slice|
    Thread.new { slice.reduce(0, :+) }
  end
  threads.map(&:value).reduce(0, :+)
end

a = (1..10_000).to_a
puts parallel_sum(a, 8) # => sum of 1..10000

Thread-safety notes

Using per-thread accumulation avoids shared-state races. If using shared counters, protect with Mutex or atomic types.
