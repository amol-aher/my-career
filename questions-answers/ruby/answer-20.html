Question 20: What is the difference between load and require in Ruby?

Concept

require loads a file once and records it in $LOADED_FEATURES. load re-evaluates the file every time it's called and can optionally wrap the evaluation in an anonymous module.

Optimal answer (concise)

Use require for libraries (idempotent). Use load when you need to reload code (e.g., development scripts) or evaluate multiple times.

Subquestions & answers

  • load with wrap: load 'file.rb', true executes inside an anonymous module, limiting namespace pollution.
  • require_relative: resolves relative to the caller file — useful for project files.

Example

# file: greet.rb
puts 'greet loaded at ' + Time.now.to_s

require './greet' # prints once
require './greet' # no-op
load './greet'    # prints again

Best practices / Pitfalls

  • Avoid mixing load/require unexpectedly — it can lead to multiple constant definitions.
