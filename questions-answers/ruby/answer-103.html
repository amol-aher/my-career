Question 103: What are race conditions? Give a simple example in Ruby.

Concept

A race condition occurs when two or more threads access shared data concurrently and the outcome depends on scheduling order, causing unpredictable results.

Optimal answer (concise)

Race conditions arise when multiple threads read/write shared state without synchronization.

Example

counter = 0
threads = 10.times.map do
  Thread.new do
    1000.times { counter += 1 }
  end
end
threads.each(&:join)
puts counter # expected 10000, but usually less due to race

Best practices

  • Use synchronization primitives like Mutex to avoid race conditions.
