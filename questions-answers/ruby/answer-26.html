Question 26: If you want to expose a method as a class method, how will you do it? Any other approach?

Concept

Expose class methods by extending the base class with a module or defining methods on the singleton class. ActiveSupport::Concern's class_methods is a common pattern.

Optimal answer (concise)

Use module ClassMethods; def foo; end; end; def self.included(base); base.extend(ClassMethods); end, or use ActiveSupport::Concern with class_methods.

Other approaches

  • Define methods directly on base.singleton_class in the included hook.
  • Use extend at include site: Base.extend(MyModule).

Example

module M
  def self.included(base)
    base.extend ClassMethods
  end
  module ClassMethods
    def greet; 'hi' end
  end
end

class C; include M; end
C.greet # => 'hi'
