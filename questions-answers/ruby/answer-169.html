Question 169: Explain how to build deterministic tests for concurrent code. What techniques and libraries help?

Concept

Deterministic tests control ordering and timing of concurrent events. Techniques include injecting synchronization points, using fake schedulers, and deterministic execution frameworks.

Optimal answer (concise)

Instrument code with hooks, use controllable schedulers (fiber-based), inject delays, and use mocking to force interleavings. Libraries may be limited in Ruby, so implement small testing frameworks to control threads/fibers in unit tests.

Techniques

  • Barriers/latches to sequence operations.
  • Thread injection points to pause/resume threads.
  • Record/replay of schedules.

Best practices

  • Focus deterministic tests on critical invariants; complement with randomized stress tests.
