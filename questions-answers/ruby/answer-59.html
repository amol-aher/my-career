Question 59: Explain the difference between instance methods and class methods.

Concept

Instance methods operate on an object of a class, with self bound to the instance. Class methods operate on the class object itself.

Optimal answer (concise)

Instance methods are defined with def name; class methods with def self.name or inside class << self.

Example

class User
  def greet; "hi" end          # instance method
  def self.find(id); ... end   # class method
end
