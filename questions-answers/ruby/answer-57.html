Question 57: How do you define a class in Ruby?

Concept

Classes are blueprints for objects, defined with class. They can contain methods, constants, and inherit from other classes.

Optimal answer (concise)

Use class Name; ... end. Inherit with <. Define instance and class methods inside.

Example

class Person
  attr_accessor :name
  def initialize(name)
    @name = name
  end
  def greet; "Hi, \#{@name}" end
  def self.species; "Homo sapiens" end
end
