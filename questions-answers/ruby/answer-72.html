Question 72: How do reduce / inject work in Ruby?

Concept

reduce (aka inject) combines all elements of an enumerable into a single value using an accumulator and a block.

Optimal answer (concise)

reduce and inject are the same. They take an optional initial value and apply the block to accumulate results.

Example

[1,2,3,4].reduce(0) { |sum, x| sum + x } # => 10
[1,2,3,4].inject(:+)                     # => 10

Subquestions & answers

  • Initial value? — If omitted, the first element is used as accumulator.
  • Symbol form? — inject(:+) uses + as block.
