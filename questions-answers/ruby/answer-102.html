Question 102: What is the difference between Thread.new and Thread.start?

Concept

Both create and start a new thread immediately, but Thread.start is an alias for Thread.new with slightly different argument handling.

Optimal answer (concise)

Thread.new and Thread.start behave almost the same. Thread.start(args) passes args to the block, like Thread.new(args). Thread.fork is also an alias.

Example

Thread.new { puts 'hi' }.join
Thread.start { puts 'hello' }.join

Best practices

  • Use Thread.new for clarity and consistency.
