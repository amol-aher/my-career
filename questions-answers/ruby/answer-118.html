Question 118: How would you parallelize IO-bound tasks in Ruby? Give examples.

Concept

IO-bound tasks benefit from concurrency (threads, fibers, async IO). Use threads, evented libraries (EventMachine), async/fiber-based libraries, or concurrent-ruby thread pools.

Optimal answer (concise)

Use threads or fiber-based async libraries. On MRI, threads can handle many concurrent IO tasks since IO operations often release the GVL. Use connection pools and backpressure.

Examples

# threads
threads = urls.map do |u|
  Thread.new { fetch(u) }
end
threads.each(&:join)

# async with concurrent-ruby futures
futures = urls.map { |u| Concurrent::Future.execute { fetch(u) } }
futures.map(&:value)

Best practices

  • Limit concurrent connections, use timeouts, and handle retries/backoff.
