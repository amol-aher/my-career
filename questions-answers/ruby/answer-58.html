Question 58: How do instance variables differ from class variables?

Concept

Instance variables (@var) belong to a specific object instance. Class variables (@@var) are shared across a class and its subclasses.

Optimal answer (concise)

@var is per-object; @@var is shared across class hierarchy. Prefer class instance variables (@var inside class << self) over class variables to avoid inheritance issues.

Example

class C
  @@shared = 0
  def initialize; @id = rand(100) end
  def id; @id end
  def self.shared; @@shared += 1 end
end
