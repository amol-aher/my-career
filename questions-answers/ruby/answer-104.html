Question 104: What is a critical section? How can you protect it in Ruby?

Concept

A critical section is a piece of code that must not be executed by more than one thread at the same time when accessing shared resources.

Optimal answer (concise)

Protect critical sections using Mutex#synchronize in Ruby.

Example

mutex = Mutex.new
counter = 0
threads = 5.times.map do
  Thread.new do
    1000.times do
      mutex.synchronize { counter += 1 }
    end
  end
end
threads.each(&:join)
puts counter # => 5000

Best practices

  • Keep critical sections small to minimize contention.
