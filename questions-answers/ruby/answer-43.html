Question 43: What exactly is metaprogramming in Ruby?

Concept

Metaprogramming is writing code that writes/changes code at runtime. Ruby's flexible object model (open classes, define_method, class_eval, method_missing) enables powerful metaprogramming used for DSLs, ORMs, and dynamic APIs.

Optimal answer (concise)

Metaprogramming lets you create methods dynamically, delegate behavior, and build DSLs. Use it to reduce boilerplate (e.g., ActiveRecord) but keep it readable and safe.

Subquestions & answers

  • Common tools: define_method, class_eval, method_missing, send, const_missing.
  • Risks: harder to reason about, possible performance overhead, and security concerns when eval-ing dynamic strings.

Example

class AttrLogger
  def self.attr_logged(*names)
    names.each do |name|
      define_method(name) do
        puts "reading \#{name}"
        instance_variable_get("@#{name}")
      end
      define_method("#{name}=") do |v|
        puts "writing \#{name} = \#{v}"
        instance_variable_set("@#{name}", v)
      end
    end
  end
end

class User < AttrLogger
  attr_logged :name, :age
end

Best practices / Pitfalls

  • Prefer explicit code for clarity; use metaprogramming where it meaningfully reduces repetition.
