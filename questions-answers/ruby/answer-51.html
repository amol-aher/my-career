Question 51: What’s the difference between puts, print, and p?

Concept

These are Ruby's basic output methods, but they differ in formatting and inspection.

Optimal answer (concise)

  • puts: adds a newline after output, calls to_s.
  • print: no newline, calls to_s.
  • p: outputs using inspect (good for debugging), adds newline.

Subquestions & answers

  • When to use p? — debugging objects (shows type/quotes/structure).
  • When to use puts/print? — user-facing output or formatted text.

Example

puts "hi"     # hi\n
print "hi"    # hi (no newline)
p "hi"        # "hi"
