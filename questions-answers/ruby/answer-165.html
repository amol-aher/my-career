Question 165: How do you decide whether to use threads, processes, or external workers for scaling?

Concept

Decision depends on workload type (CPU vs IO), need for isolation, memory constraints, and ecosystem (gems, native extensions).

Optimal answer (concise)

Use processes for CPU-bound tasks on MRI and for isolation. Use threads (or fibers) for IO-bound concurrency, especially on runtimes that allow parallelism (JRuby). Use external workers/services for heavy or long-running jobs and polyglot needs.

Decision factors

  • CPU-bound? → processes or JRuby. IO-bound? → threads/fibers.
  • Need isolation? → processes or external services.
  • Memory constraints? → threads use less memory but watch for GVL limits on MRI.

Best practices

  • Profile and prototype; don't assume — measure and choose the least complex solution that meets requirements.
