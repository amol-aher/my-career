Question 175: Compare performance of a CPU-bound workload implemented with threads vs using multiple processes (fork) on MRI. Measure and report. (Advanced: include measurement scripts)

Concept

Provide a measurement script and guidance for running benchmarks to compare threads vs processes on MRI. Include warmup, CPU affinity, and multiple runs to average results.

Optimal answer (concise)

Processes scale on multi-core machines for CPU-bound tasks on MRI. Threads won't improve CPU-bound performance due to GVL. Use provided scripts to measure on your hardware.

Measurement script (example)

# benchmark.rb
require 'benchmark'
def heavy(n); (1..n).map { |i| Math.sqrt(i) }.reduce(:+) end
workers = (ARGV[0] || 4).to_i
n = (ARGV[1] || 5_000_000).to_i

Benchmark.bm do |x|
  x.report('threads') do
    threads = workers.times.map { Thread.new { heavy(n) } }
    threads.each(&:join)
  end

  x.report('processes') do
    pids = workers.times.map { fork { heavy(n); exit 0 } }
    pids.each { |pid| Process.wait(pid) }
  end
end

Notes

Run multiple iterations, set CPU affinity if possible, and consider process startup overhead. Expect processes to show near-linear scaling up to core count.
