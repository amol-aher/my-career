Question 76: What’s the difference between String#dup and String#clone?

Concept

Both create a shallow copy of a string, but clone preserves frozen state and singleton methods, while dup does not.

Optimal answer (concise)

dup makes a shallow copy without frozen state; clone preserves frozen and tainted state and singleton methods.

Example

s = "hi".freeze
s.dup.frozen?    # => false
s.clone.frozen?  # => true

Best practices

  • Use dup for everyday duplication; clone when you need to preserve state.
