Question 98: Show how you would use Enumerable#inject to calculate a factorial.

Concept

Use inject (reduce) to multiply the sequence from 1 to n.

Optimal answer (concise)

(1..n).inject(1) { |acc, x| acc * x }

Code

def factorial(n)
  return 1 if n <= 1
  (1..n).inject(1) { |acc, x| acc * x }
end

factorial(5) # => 120
