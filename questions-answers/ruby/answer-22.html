Question 22: Have you ever used decorators?

Concept

Decorators wrap objects to add behavior without modifying original classes. In Ruby, patterns include wrapper objects, Draper gem for view decorators, or singleton methods/extensions for single instances.

Optimal answer (concise)

Yes — decorators are useful for presentation logic or adding behavior to specific instances without changing the class.

Subquestions & answers

  • Decorator pattern: maintain original object interface and delegate unknown methods.
  • Instance extension: obj.extend(Module) modifies a single object.

Example

class UserDecorator
  def initialize(user) @user = user end
  def display_name; [@user.first_name, @user.last_name].compact.join(' ') end
  def method_missing(m, *a, &b) @user.public_send(m, *a, &b) end
end

Best practices / Pitfalls

  • Keep decorators focused (presentation-focused) and avoid putting business logic there.
