Question 91: How would you optimize slow Ruby code?

Concept

Optimizing Ruby code involves identifying hotspots via profiling, reducing allocations, simplifying algorithms, and applying appropriate concurrency or native extensions.

Optimal answer (concise)

Profile first (stackprof, ruby-prof), focus on the hot paths, reduce allocations, optimize algorithms/data structures, cache results, and consider moving CPU-heavy parts to native extensions or separate services.

Subquestions & answers

  • Allocation reduction: reuse objects, avoid creating many temporary strings, use frozen literals.
  • Algorithmic improvements: choose appropriate data structures (hash vs array) and avoid O(n^2) patterns.
  • IO optimization: batch database queries, use appropriate indexes, and preload associations.

Example

# before: N+1 query
users.each { |u| puts u.posts.count }

# after: preload
users = User.includes(:posts)
users.each { |u| puts u.posts.size }

Best practices / Pitfalls

  • Measure before and after changes; premature optimization can add complexity.
  • Always profile in an environment similar to production.
